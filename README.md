# Stock Analysis Framework

融合两套A股分析系统精华的统一股票分析方法论。

## 版本: V3.1.0 (2026-08-06)

## 分析流程: 9步法

| 步骤 | 内容 | 数据源 |
|------|------|--------|
| -1 历史复盘 | 检查历史报告,验证上次结论 | 文件系统 |
| 1 前复权 | 除权记录+手动复权计算 | mootdx xdxr |
| **2 市场环境** | **大盘+北向+板块TOP+个股所属板块(sector_analysis.py)** | **腾讯+东财+脚本** |
| 3 量价关系 | 逐日K线+成交量→判断主力阶段+3日组合形态 | 东财K线 |
| 4 资金流向 | 主力/散户/超大单20日逐日(东财API直连+镜像重试) | 东财push2his |
| 5 均线技术 | MA5/10/20/30+偏离度+排列+Fibonacci+MACD背驰 | K线计算 |
| 6 情绪周期 | 换手率量化+情绪底部/顶部特征(由agent手工判断) | 腾讯行情 |
| 7 估值基本面 | PE/PB/PEG+预期差分析(基础数据由脚本采集,深度分析由agent完成) | 腾讯+akshare |
| 8 概念板块 | 完整概念映射+龙头识别+核心vs蹭概念 | 同花顺+东财 |
| 9 消息面 | 事件驱动分类+利好兑现出货+风险筛查 | news_analysis.py |

## 数据采集脚本

```bash
# 10步模板数据采集(输出JSON)
python3 scripts/deep_analysis.py <股票代码> [名称]
# 输出: /tmp/deep_analysis_<code>.json
```

⚠️ deep_analysis.py是数据采集器,输出原始数据JSON。分析结论由agent基于JSON数据撰写。

## 文件结构

```
SKILL.md                    # 主分析框架(V3.1.0, 9步法)

```

## 评分体系(100分制)

| 维度 | 权重 | 说明 |
|------|------|------|
| 量价关系 | 30% | 主力行为阶段+量价评分 |
| 技术面 | 25% | 均线排列(MA5/10/20/30)+趋势强度 |
| 资金面 | 20% | 主力资金流向验证(空值→中性10分) |
| 消息面 | 15% | 情绪+催化+风险(脚本默认7.5/15,agent覆盖) |
| 估值面 | 10% | PE/PEG/基本面安全边际 |
