## 四-B、持仓成本分析模板（用户问"加仓还是减仓"）

当用户持有某只股票并问"要不要加仓/减仓/止损"时，需要在标准分析基础上
增加持仓维度的分析。与纯研究型分析不同，这类请求需要给出明确的
"加仓/减仓/持有/止损"四选一建议。

### 分析流程
1. 先做完整的量价+资金+估值分析（同标准流程）
2. 增加持仓维度:
   - 计算当前价 vs 成本价的偏离度
   - 评估回本概率（基于技术面支撑/压力位）
   - 判断主力出货是否已充分（筹码换手率）
3. 给出四选一明确建议，不允许模糊

### 输出模板
```
== 持仓状况 ==
  成本价: XX.XX | 当前价: XX.XX | 浮盈/亏: X.XX%
  回本需涨: X.XX%

== 操作建议(四选一) ==
  ⛔ 不加仓 + 原因(1/2/3)
  ⚠️ 不立即止损 + 原因(1/2/3)
  ✅ 持有等待 + 观察信号

== 具体操作方案 ==
  场景                操作                触发条件
  反弹至成本附近       减仓30%降风险       接近成本价
  回落至支撑位         小仓补仓(≤20%)     二次探底
  跌破支撑位           止损50%            趋势走坏

== 回本概率评估 ==
  X%概率: N周内回到成本价
  Y%概率: 反弹至更高位
  Z%概率: 需要止损
```

### 关键原则
- 必须给出明确建议，不允许"看情况"式模糊回答
- 加仓条件必须严格：需同时满足量价+资金+估值
- 减仓/止损条件必须具体到价格
- 仓位管理建议要量化（减仓30%、补仓≤20%等）

## 三-B、新仓买入评估模板（用户问"现在是否值得买入"）

当用户问"XX现在能不能买/值得买入吗"时，使用此模板。
**与加仓决策(第四节)的区别**：加仓是已持仓用户问要不要加仓，新仓是从零建仓。

### 买入信号三要素（缺一不可）

李成刚策略的买入条件是**三个条件同时满足**，不是"满足一个就可以"：

| 条件 | 要求 | 不满足时 |
|------|------|---------|
| ① 缩量比 | < 0.8 | 抛压未减轻，不是洗盘尾声 |
| ② K线信号 | 十字星/长下影/双针探底 | 缺乏止跌确认信号 |
| ③ R:R比 | > 1.0（最好>2.0） | 风险远大于收益，不值得冒险 |

**⚠️ R:R比是最常被忽略但最关键的条件：**
- R:R = (阻力位-现价) / (现价-支撑位)
- R:R < 1 = 下跌空间 > 上涨空间 = 不划算
- 即使缩量+十字星都满足，R:R < 1 也不应买入
- 常见陷阱：MA20偏离过大(>15%)的票，R:R几乎必然<1

### R:R比计算与解读

```python
# R:R = 上涨空间 / 下跌空间
resistance = 前高 or 阻力位
support = MA20 or 前低 or 支撑位
rr = (resistance - current_price) / (current_price - support)

# 解读
# R:R > 2.0 → 优秀（上涨空间是下跌的2倍以上）
# R:R 1.0-2.0 → 可接受
# R:R < 1.0 → 不值得冒险（下跌空间大于上涨空间）
# R:R < 0.5 → 极差（几乎必亏的赔率）
```

**⚠️ R:R边界情况: 价格跌破或贴近支撑位时**

当current_price <= support时,分母为零或负数,R:R公式失效。
这发生在:价格已跌破MA20/前低等支撑位,或正在测试支撑位。

正确处理:
```python
if current_price <= support:
    # 价格已破支撑或贴着支撑,R:R公式分母<=0
    # 用当日最低价或下一级支撑位(MA30/前期低点)重新计算
    new_support = day_low or MA30 or prior_low
    if current_price > new_support:
        rr = (resistance - current_price) / (current_price - new_support)
    else:
        rr = 0  # 全面破位,无法计算
```

案例(凯盛科技7/6): 现价25.10 ≈ MA20(25.06),用当日低点24.31做支撑 → R:R=2.08
但如果跌破24.31且无新支撑确认 → R:R无效,应观望

**为什么高位票R:R必然差：**
- 价格在MA20上方很远 → support(支撑位)距离远 → 下跌空间大
- 前高距离近 → resistance(阻力位)距离近 → 上涨空间小
- 结果：R:R极低，即使方向判断正确也赚不到钱

**箱体策略增强R:R计算（V2.2新增）**:

当股价在横盘震荡区间内运行时，用箱体区间替代简单的前高/前低计算R:R。

**箱体识别方法**:
```python
# 识别近60日的箱体区间
highs = bars['high'].iloc[-60:]  # 近60日最高价
lows = bars['low'].iloc[-60:]    # 近60日最低价

# 箱体顶部: 多次触碰但未有效突破的高点连线(≥3次)
# 箱体底部: 多次下探但未有效跌破的低点连线(≥3次)
box_high = highs.quantile(0.90)  # 用90分位数近似箱顶
box_low = lows.quantile(0.10)   # 用10分位数近似箱底

# 箱体位置判断
box_position = (current_price - box_low) / (box_high - box_low)
# 0 = 箱底, 1 = 箱顶
```

**箱体位置与R:R的关系**:

| 箱体位置 | 含义 | R:R调整 |
|---------|------|--------|
| 0-0.2 (箱底附近) | 低估区间，下跌空间有限 | R:R有利(+0.3分) |
| 0.2-0.5 (下半区) | 相对安全 | R:R正常 |
| 0.5-0.8 (上半区) | 接近阻力 | R:R偏弱 |
| 0.8-1.0 (箱顶附近) | 高估区间，上涨空间有限 | R:R不利(-0.2分) |

**箱体策略操作规则**:
- 价格在箱体下轨(0-0.2) + 缩量 → 买入机会(箱体下沿买入)
- 价格在箱体上轨(0.8-1.0) + 放量 → 减仓机会(箱体上沿卖出)
- 价格突破箱顶 + 放量确认 → 箱体突破，趋势启动
- 价格跌破箱底 + 放量确认 → 箱体破位，止损离场

**箱体策略的陷阱**:
- 箱体不是永恒的，可能被突破或破位
- 只在箱体内有效，突破后需切换回趋势策略
- 假突破: 突破后立即回落 → 需要收盘价确认(不能只看盘中)

**Fibonacci回撤位（V3.0新增，源自波浪理论）**:

波浪理论的核心量化工具是Fibonacci回撤比例。当股价从高点回调时，
关键支撑位往往出现在Fibonacci回撤位上。

**计算方法**:
```python
# 选取一段明确的趋势(最近一波上涨或下跌)
swing_high = 近期最高价(如30日内最高)
swing_low = 近期最低价(如30日内最低)

# 计算Fibonacci回撤位(从高点回调)
fib_382 = swing_high - (swing_high - swing_low) * 0.382  # 38.2%回撤
fib_500 = swing_high - (swing_high - swing_low) * 0.500  # 50%回撤
fib_618 = swing_high - (swing_high - swing_low) * 0.618  # 61.8%回撤
fib_786 = swing_high - (swing_high - swing_low) * 0.786  # 78.6%回撤

# 计算Fibonacci扩展位(突破后目标)
fib_ext_1272 = swing_low + (swing_high - swing_low) * 1.272  # 127.2%扩展
fib_ext_1618 = swing_low + (swing_high - swing_low) * 1.618  # 161.8%扩展
```

**Fibonacci回撤位与支撑/阻力的关系**:

| 回撤位 | 含义 | 操作参考 |
|--------|------|---------|
| 38.2% | 强势回调(浅回撤) | 趋势延续概率高,可加仓 |
| 50.0% | 中度回调 | 关键观察位,需配合其他信号 |
| 61.8% | 深度回调(黄金分割) | 最重要的支撑位,跌破则趋势可能反转 |
| 78.6% | 极深回调 | 趋势反转概率高,需止损 |

**Fibonacci在R:R计算中的应用**:
```python
# 用Fibonacci回撤位作为支撑位
if current_price > fib_618:
    support = fib_618  # 61.8%回撤是最强支撑
elif current_price > fib_500:
    support = fib_500
else:
    support = fib_382  # 浅回撤支撑

# R:R = (阻力位-现价) / (现价-Fibonacci支撑位)
rr = (resistance - current_price) / (current_price - support)
```

**⚠️ Fibonacci使用的注意事项**:
- 必须选取**明确的趋势段**(不是随机选高低点)
- 上涨趋势回调: 从高点向下计算回撤位(支撑)
- 下跌趋势反弹: 从低点向上计算回撤位(阻力)
- Fibonacci不是精确的支撑/阻力,而是**区间**(±2%容差)
- 需要配合其他信号(量价/K线形态)确认,不能单独使用

**双Fibonacci反弹评估框架（V3.1新增，2026-07-29）**:

当个股经历大跌(-30%+)后出现V型反弹,必须同时用两个Fibonacci回撤评估:
1. **大级别回撤**(从大跌起点到低点) → 衡量反弹强度(是否到达38.2%"及格线")
2. **小级别回撤**(从低点到反弹高点) → 衡量回调支撑位

| 反弹高度(大级别) | 含义 | 操作 |
|---------|------|------|
| 未到38.2% | 极弱反弹,大概率继续下跌 | 不参与 |
| 到38.2%受阻 | 弱势反弹,中期趋势未反转 | 观望,不追高 |
| 突破38.2%到50% | 中等反弹,有反转潜力 | 关注,等待确认 |
| 突破61.8% | 强势反弹,趋势可能反转 | 可考虑建仓 |

关键教训:
- 许继电气: 大+小级别38.2%回撤重合在21.78→精确支撑→逆势走强
- 雷赛智能: 大级别38.2%回撤60.76受阻→弱势反弹→非趋势反转
详见 `stock-analysis-reference/references/dual-fibonacci-bounce-assessment.md`

**MACD背驰检测（V3.0新增，源自缠论）**:

缠论的核心量化工具是MACD背驰(背离)检测。当价格与MACD指标出现背离时,
往往预示趋势即将反转。

**背驰类型**:

| 类型 | 价格表现 | MACD表现 | 含义 |
|------|---------|---------|------|
| 顶背离 | 价格创新高 | MACD柱/DIF未创新高 | 上涨动能衰竭,见顶信号 |
| 底背离 | 价格创新低 | MACD柱/DIF未创新低 | 下跌动能衰竭,见底信号 |
| 零轴上金叉 | DIF上穿DEA | 在零轴上方 | 强势延续信号 |
| 零轴下金叉 | DIF上穿DEA | 在零轴下方 | 弱势反弹信号 |

**顶背离检测**:
```python
# MACD计算
ema12 = close.ewm(span=12).mean()
ema26 = close.ewm(span=26).mean()
dif = ema12 - ema26
dea = dif.ewm(span=9).mean()
macd_bar = (dif - dea) * 2

# 顶背离检测: 价格创新高但MACD未创新高
price_new_high = close[-1] > close[-20:].max()  # 价格创20日新高
macd_not_new_high = dif[-1] < dif[-20:].max()   # DIF未创新高

if price_new_high and macd_not_new_high:
    signal = "顶背离"
    # 操作: 减仓或观望,上涨动能衰竭
```

**底背离检测**:
```python
# 底背离检测: 价格创新低但MACD未创新低
price_new_low = close[-1] < close[-20:].min()    # 价格创20日新低
macd_not_new_low = dif[-1] > dif[-20:].min()     # DIF未创新低

if price_new_low and macd_not_new_low:
    signal = "底背离"
    # 操作: 关注买入机会,下跌动能衰竭
```

**背驰强度判断**:
| 背驰强度 | 条件 | 操作含义 |
|---------|------|---------|
| 强背驰 | 价格新高/低 + MACD偏离>30% | 趋势反转概率高 |
| 中背驰 | 价格新高/低 + MACD偏离10-30% | 趋势可能反转,需确认 |
| 弱背驰 | 价格新高/低 + MACD偏离<10% | 仅作为参考,不作为主要依据 |

**⚠️ 背驰使用的注意事项**:
- 背驰只是**预警信号**,不是买卖信号
- 顶背离后可能继续上涨(强势市场),需要配合其他信号确认
- 底背离后可能继续下跌(弱势市场),需要配合缩量/K线确认
- 背驰检测的时间框架: 至少20日,建议用60日提高准确性
- 缠论的"背驰"和我们常说的"背离"是同一个概念

### 评估流程

```
Step 1: 扫描脚本获取技术指标
  → scan_candidate.py 输出: 缩量比/MA20偏离/K线形态/R:R/评分

Step 2: 三要素检查（按优先级）
  ① R:R > 1.0? → 不满足直接PASS，不看其他条件
  ② 缩量比 < 0.8? → 不满足需等待
  ③ 十字星/长下影? → 不满足需等待

Step 3: 如果三要素都满足，再看：
  - 均线排列（多头加分，空头减分）
  - 资金流向（净流入加分，净流出减分）
  - 消息面（利好加分，利空减分）
  - 估值（PE合理加分，泡沫减分）

Step 4: 综合判断
  - 三要素全满足 + 均线多头 + 资金流入 → 🟢 可建仓
  - 三要素全满足 + 其他条件有瑕疵 → 🟡 小仓位试探
  - 三要素任一不满足 → 🔴 等待，不买入
```

### 输出模板

```
== 买入信号评估: {股票名}({代码}) ==

扫描结果:
  缩量比: X.XX ✅/❌ (阈值0.8)
  MA20偏离: +X.X% ✅/❌
  K线形态: [十字星/长下影/无] ✅/❌
  R:R比: X.XX ✅/❌ (阈值1.0)
  扫描评分: X/5

三要素检查:
  ① 缩量比<0.8: ✅/❌
  ② K线信号: ✅/❌
  ③ R:R>1.0: ✅/❌
  三要素满足: X/3

R:R详细计算:
  现价: XX.XX
  阻力位(前高): XX.XX → 上涨空间 +X.X%
  支撑位(MA20/前低): XX.XX → 下跌空间 -X.X%
  R:R = X.XX

板块/概念:
  所属板块: [板块名]
  板块近期表现: [活跃/调整/震荡]
  个股vs板块: [强于板块/弱于板块/同步]

综合结论:
  🟢 三要素全满足 → 可建仓(仓位X%)
  🟡 缩量+K线满足但R:R勉强 → 等回调再买
  🔴 任一要素不满足 → 等待，不买入
  止损位: XX.XX (支撑位下方X%)
```

### 常见场景判断

| 场景 | 缩量 | K线 | R:R | 结论 |
|------|------|-----|-----|------|
| 高位缩量十字星 | ✅ | ✅ | ❌ (<1) | 🔴 不买（R:R太差） |
| MA20附近缩量长下影 | ✅ | ✅ | ✅ (>2) | 🟢 可买 |
| 放量上涨无缩量 | ❌ | ❌ | ✅ | 🔴 不买（主力可能在出货） |
| 缩量但无K线信号 | ✅ | ❌ | ✅ | 🟡 等待K线确认 |
| 低位缩量+十字星+R:R好 | ✅ | ✅ | ✅ | 🟢 理想买点 |

### 关键原则
- **R:R是第一道门槛**：不满足直接PASS，不看其他条件
- **宁可错过，不要追高**：缩量到位但R:R差 = 等回调
- **仓位控制**：即使买入，首仓不超过总资金10-20%
- **必须有止损**：买入时必须同时设好止损位

## 四、加仓决策模板

```
== 量价关系定性 ==
  [描述近期K线量价配合情况，判断主力处于哪个阶段]
  量价评分: X/5
  关键K线(判断依据): 2-3根
    日期 + 开/收/高/低 + 成交量(vs前日%) + 为什么

== 加仓信号检查(5项) ==
  ✅/❌ 量价关系确认主力未出货
  ✅/❌ 均线多头排列 (MA5>MA10>MA20>MA30)
  ✅/❌ 价格站稳MA10上方 (连续N日)
  ✅/❌ 主力资金从流出转为连续N日流入
  ✅/❌ 估值处于合理区间 (PE行业均值附近/PEG<1.5)
  信号满足数: X/5

== 风险筛查 ==
  [列出检查到的风险项，标注severity]

== 综合评分 ==
  量价X分×30% + 技术X分×25% + 资金X分×20% + 消息X分×15% + 估值X分×10%
  = XX分

== 加仓结论 ==
  🟢 80+ → 可加仓
  🟡 60-79 → 谨慎加仓(小仓位)
  🟡 40-59 → 观望等待
  🔴 20-39 → 不建议加仓/考虑减仓
  🔴 <20 → 止损/清仓
```

### scan_candidate.py 输出解读

脚本输出每只股票的综合评分(0-5分)，但**高评分≠可以买入**。

**评分构成**：
- 缩量比 ✅ (+1分)
- MA20上方 ✅ (+1分)
- 十字星/长下影 ✅ (+1分)
- R:R > 1 ✅ (+1分)
- 均线多头 ✅ (+1分)

**关键陷阱：评分4-5分但R:R<1的票不能买！**

常见场景：
- 缩量✅ + 十字星✅ + MA20上方✅ + 均线多头✅ = 4分
- 但R:R=0.2 ❌（MA20偏离+25%，支撑位太远）
- 结论：4分看起来很好，但R:R是致命短板，不能买

**正确解读顺序**：
1. 先看R:R → <1直接PASS，不看评分
2. 再看缩量比 → <0.8才有效
3. 最后看综合评分 → 作为辅助参考

**R:R差的原因通常是**：
- 股价在MA20上方很远（偏离>15%）
- 前高距离近，上涨空间有限
- 这种票即使方向对了也赚不到钱

   - 板块内其他标的走势（是否同步）

   - 板块活跃 + 个股高位 → 追高风险大
   - 板块调整 + 个股低位 → 等板块企稳再买
   - 板块调整 + 个股高位 → 风险最大，远离

### 市场全景扫描工作流（用户问"扫描市场"时使用）

当用户问"扫描一下市场情况"时，按以下流程执行：

**Step 1: 大盘指数** — mootdx quotes获取上证/深证/创业板实时数据

**Step 2: 涨跌家数统计** — 核心步骤，用于判断赚钱效应
```python
from mootdx.quotes import Quotes
import pandas as pd
client = tdx_client()  # 见 a-stock-data V3.3.0 Prerequisites

# 获取股票列表（注意: stocks()只返回code/name/pre_close元数据，不含价格）
sh = client.stocks(market=1)  # 沪市
sz = client.stocks(market=0)  # 深市

# 过滤A股
sh_a = sh[sh['code'].str.match(r'^[06]')]
sz_a = sz[sz['code'].str.match(r'^[03]')]
all_codes = pd.concat([sh_a, sz_a])['code'].tolist()

# 批量获取实时报价（分批100只，mootdx quotes支持批量）
all_data = []
for i in range(0, len(all_codes), 100):
    batch = all_codes[i:i+100]
    try:
        df = client.quotes(symbol=batch)
        if df is not None and not df.empty:
            all_data.append(df)
    except:
        pass

# 计算涨跌统计
result = pd.concat(all_data, ignore_index=True)
result = result[result['price'] > 0]
result['chg'] = (result['price']/result['last_close']-1)*100

total = len(result)
up = (result['chg'] > 0).sum()
down = (result['chg'] < 0).sum()
limit_up = (result['chg'] >= 9.9).sum()
limit_down = (result['chg'] <= -9.9).sum()
med_chg = result['chg'].median()

# 涨幅分布
bins = [(-100,-7),(-7,-5),(-5,-3),(-3,0),(0,3),(3,5),(5,7),(7,10),(10,100)]
labels = ['<-7%','-7~-5%','-5~-3%','-3~0%','0~3%','3~5%','5~7%','7~10%','>10%']
for (lo,hi), label in zip(bins, labels):
    count = len(result[(result['chg']>=lo)&(result['chg']<hi)])
```

⚠️ 已知限制:
- mootdx `stocks()` 返回的DataFrame只有 `code/volunit/decimal_point/name/pre_close` 五列，**不含实时价格**
- 必须用 `quotes()` 批量获取实际价格，分批100只避免超时
- 6000+只股票全量获取约需30-60秒
- 部分股票(price=0)需要过滤

**Step 3: 板块/概念热点** — 用mx-search或web_search获取当日市场主线

**Step 4: 关注个股快扫** — mootdx quotes批量获取用户持仓/关注个股

**Step 5: 资金面** — 两融余额、融资买入占比等

**关键判断指标**:
- 中位数涨幅 > 0 → 赚钱效应好
- 中位数涨幅 < -1% → 亏钱效应明显
- 涨停/跌停比 → 情绪温度
- 上涨比例 > 60% → 普涨; < 30% → 结构性分化
- 成交额 → 量能活跃度

1. 列出每只票的完整概念标签
2. 标注重叠概念 vs 独有概念
3. 概念重叠度高 → 差异在催化节奏/估值/资金轮动
4. 概念重叠度低 → 差异在板块轮动/风格切换

```

  概念重叠度: 高/中/低

```

### ⭐ 板块横向对比分析工作流 (同板块多股分化原因分析)

当用户问"为什么同板块A涨B不涨"/"板块内走势差异"时，使用此6维度分析框架:

#### Step 1: 概念重叠+催化差异
- 列出每只票的完整概念标签(东财eastmoney_concept_blocks / 同花顺reason)
- 标注重叠概念 vs 独有概念
- 独有催化: 谁有近期新增催化(研报/政策/订单/国企改革等)
- 概念纯度: 谁是龙头(营收>50%) vs 蹭概念(<5%)

#### Step 2: 资金流向对比(核心)
- 逐日对比主力净流入/流出(东财push2his 20日)
- 识别"板块内资金切换": 同一天A净流入+B净流出 = 资金从B切到A
- 计算N日累计净流入, 排序谁是资金宠儿
- **关键指标**: 6日主力累计净流入差异可解释>60%的走势分化

#### Step 3: 估值压力差异
- PE/PB横向对比, 谁贵谁便宜
- 高PE(>150)是最大负担 — 市场对高估值更谨慎
- 定增/增发增加股本摊薄压力
- 亏损股炒"困境反转" vs 高PE股炒"成长预期"

#### Step 4: 技术面正反馈/负反馈
- 多头排列(越涨越吸引跟风盘) vs 空头排列(越跌越引发止损盘)
- 均线排列对比: 谁多头/谁空头/谁纠缠
- 价格在25日区间中的位置(高位80%+ vs 低位20%-)

#### Step 5: 主力行为阶段差异
- 谁在建仓/拉升(放量+资金流入) vs 谁在出货(高位+资金流出)
- 见顶信号: 长上影线+天量+后续资金持续流出
- 主力建仓信号: 巨量资金单日涌入(>总市值3%)

#### Step 6: 股价/市值/概念属性差异
- 低价股(10-20元)更受游资偏好(想象空间大)
- 国企改革催化 vs 民营企业(缺乏额外催化)
- 市值大小影响资金撬动难度

```

对比总表:
  指标         票A       票B       票C
  ──────────────────────────────────────────
  今日涨跌     x%        x%        x%
  N日涨跌      x%        x%        x%
  PE_TTM       xx        xx        xx
  主力N日流    x亿       x亿       x亿
  均线排列     多/空/缠  多/空/缠  多/空/缠
  25日位置     x%        x%        x%
  ──────────────────────────────────────────

走势分化原因(按重要性排序):
  ① [核心原因]: 资金选择差异/催化差异/估值差异
  ② [次要原因]: 技术面/主力行为/概念纯度
  ③ [辅助原因]: 股价/市值/属性

投资启示:
  板块内选谁: 票A > 票B > 票C (理由)
  操作差异: A可持有 vs B应减仓 (理由)
```

**⚠️ 常见陷阱**:
- 不能说"板块退潮"来解释个股弱于板块 → 必须区分板块整体 vs 个股问题
- 同板块不同命运的核心是"资金选择了谁", 不是基本面差异
- 资金流向数据(6日累计)是最硬的证据, 其他维度是辅助解释

## 八、复盘暴跌原因分析模板

当用户要求"复盘"、"暴跌原因"、"为什么跌这么多"时，执行以下流程:

### 分析维度（6步）

1. **K线走势回溯** — 用mootdx拉60日K线，标注关键节点(起涨点、每次涨停/跌停日期、量能变化)
2. **概念/题材归因** — 搜索是什么概念/事件驱动了前期上涨
3. **基本面核实** — 用腾讯行情拉PE/PB/市值，检查基本面是否支撑股价
4. **公司自证** — 搜索公司公告(异常波动公告/风险提示/澄清公告)，公司自己怎么说
5. **资金流向** — 东财push2his拉20日资金流，看主力何时开始出逃
6. **出货手法识别** — 判断是哪种出货模式

### 概念炒作股 vs 真实业务股 判断框架

⚠️ 2026-06-12 教训: 沃格光电/彩虹股份/五方光电都是"玻璃基板概念"，
但只有沃格和戈碧迦有真实半导体TGV业务，彩虹做的是LCD面板玻璃
(技术路线完全不同)。用户问"哪些是真正有业务的"，需要区分。

判断标准:
```
1. 公司自己怎么描述这块业务?
   → 搜索"F10公司概况" + 最新异常波动/风险提示公告
   → 如果公司说"尚处于早期阶段/研发验证/未形成规模" = 画饼

2. 该业务占营收比例多少?
   → 搜索"公司年报/半年报 分业务收入"
   → 营收占比<5% = 概念大于实质

3. 技术路线是否真的对口?
   → 搜索"公司产品 技术路线 vs 概念要求"
   → 彩虹做LCD面板玻璃 vs 半导体TGV封装玻璃 = 完全不同赛道

4. 有没有真实客户和订单?
   → 搜索"公司供货 客户名称 订单规模"
   → 有量产+有营收+有客户 = 真实业务

5. 估值是否合理?
   → PE>100 或 PB>10 或亏损 → 纯概念支撑
```

### 出货手法识别模板

| 手法 | 特征 | 案例 |
|------|------|------|
| 涨停出货 | 涨停→次日高开低走→高倍量阴线 | 深科技5/27 |
| 拉高出货 | 拉升日放量流入→次日放量流出 | 长电科技5/26-5/27 |
| 天量天价 | 成交量创新高+价格在高位=见顶 | 沃格光电6/10 |
| 连续跌停 | 利空/资金断裂导致恐慌性抛售 | 协鑫能科6/8-6/10 |
| 阴跌出货 | 缩量阴跌，主力每天少量出 | 中国西电5/14-至今 |
| 三次涨停出货 | 连续涨停吸引跟风→每次涨停次日天量出货 | 中国西电6/15-6/23 |
| 两波出货 | 第一波天量暴跌→中继平台整理5-15日→第二波暴跌创新低 | 双环传动7/6-7/20 |
| 利好兑现出货 | 利好公告发布当天即见顶→天量天价→连续暴跌 | 通富微电7/14-7/20 |

### 出货完成度评估（量化判断底部）

当量价+资金流已确认出货后，需要量化评估出货是否已接近尾声，判断是否可以开始关注底部信号。

**计算方法**:
```
流入阶段: 拉升/涨停期间主力累计净流入(如三次涨停日合计+31.5亿)
流出阶段: 出货期间主力累计净流出(如6/17-7/8合计-34.74亿)
净额 = 流出阶段 - 流入阶段

判断:
  净额 < 流入额 → 出货进行中(还有筹码要出)
  净额 ≈ 流入额 → 出货基本完成(筹码已大部分换手)
  净额 > 流入额 → 出货超额完成(可能有新增抛压,如融资盘/止损盘)
```

**出货完成后的底部信号检查**:
1. 抛压收窄: 最近1-3日流出金额大幅缩小(如从-2亿收窄至-0.3亿)
2. 缩量企稳: 成交量萎缩至拉升期的30-50%
3. 长下影探底: 盘中暴跌后尾盘拉回(下方有承接)
4. 板块/大盘强但个股弱: 资金偏好不在该方向,需要等轮动

⚠️ **出货完成 ≠ 可以买入**。出货完成后可能进入:
- 底部横盘(2-3周缩量整理) → 最佳情况
- 继续阴跌(散户止损盘+融资盘) → 还需等待
- V型反弹(超跌反弹) → 短线机会但趋势未反转

**案例(中国西电 2026-07-09)**:
- 流入: 6/15+6/16+6/22三次涨停日主力合计+31.5亿
- 流出: 6/17-7/8主力合计-34.74亿
- 净额(-34.74) > 流入(+31.5) → 出货超额完成
- 但7/6-7/8仍有-3.54亿流出 → 尾部抛压未完全消除
- 7/8流出-0.33亿(大幅收窄) → 抛压接近尾声信号
- 7/9盘中暴跌至12.61后拉回13.31 → 长下影探底(但需次日确认)
