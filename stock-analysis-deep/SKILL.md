# 深度分析9步法

> 前置: 先加载 stock-analysis-core 了解红线规则和流程概览
> 数据: 配合 a-stock-data skill 获取实时数据

### 步骤-1: 历史分析复盘（深度分析时必做）

当用户说"深度分析XX"时，在正式分析前先检查历史记录：

**操作**:
1. 搜索历史报告:
   ```bash
   search_files(pattern="*分析报告*", target="files", path="/home/harry/stock-reports/{股票名}_{代码}")
   ```
   + `session_search(query="{股票名} {代码} 分析")`

2. 如果找到历史报告:
   - 读取报告中的操作建议/支撑位/阻力位/主力判断/综合评分
   - 拉取当前数据(腾讯行情)对比价格变化
   - 输出复盘:
   ```
   == 历史复盘: {股票名}({代码}) ==
   上次分析: {日期} | 当时价格: {XX.XX}
   当前价格: {XX.XX} | 区间涨跌: {+X.XX%}

   上次结论验证:
     ✅/❌ {结论1} → 实际: {验证结果}
     ✅/❌ {结论2} → 实际: {验证结果}
     ...

   上次遗漏:
     {哪些因素没考虑到，导致判断偏差}

   本次需重点关注:
     {基于上次遗漏+当前新情况的特别关注点}
   ```

3. 如果没有历史报告:
   - 跳过，正常执行后续步骤

**⚠️ 关键规则**:
- 复盘结果放在分析报告最前面(在市场环境之前)
- 复盘必须诚实: 上次判断对了就说对了，错了就说错了
- 遗漏分析是核心价值: 哪些因素没考虑到？为什么没考虑到？下次如何避免？
- 如果上次的支撑位/阻力位被击穿，本次分析必须重新计算
- **⚠️ 历史报告的K线数据也可能错误**: 子agent可能编造K线数据(如通富微电79.39案例: 子agent将6/25高点79.38错误归因为7/10开盘价79.39,41处引用全部错误)。读取历史报告时需对关键K线数据做基本校验: 开盘价应在最高最低之间,涨停价=前收盘×涨跌幅限制。详细案例见 `stock-analysis-reference/references/kline-data-fabrication-case-study.md`

### 步骤1: 前复权处理（必做，在所有分析之前）

⚠️ 2026-06-15教训: 不复权会导致支撑阻力位、均线偏离、量价关系全部失真。

**操作**:
1. 先查除权记录: `client.xdxr(symbol=code)` 获取近期分红/转增
2. 确认分析周期内是否有除权(特别是近60日内)
3. 如果有除权(category=1):
   - 前复权: 旧行情(除权前) = 原始价 / 复权因子 - 每股派息
   - 复权因子 = 1 + songzhuangu/10 (送转股)
   - 除权后行情无需调整
4. 所有均线、支撑阻力、偏离度计算都基于复权价
5. mootdx的adjust='qfq'有pandas兼容bug，需手动计算

```python
# 示例: 5/21 10转2 + 每10股派0.75元
ex_date = pd.Timestamp('2026-05-21')
factor = 1.2  # 1 + 2/10
dividend_per_share = 0.075  # 0.75/10

mask = bars.index < ex_date
bars.loc[mask, 'adj_close'] = bars.loc[mask, 'close'] / factor - dividend_per_share
bars.loc[mask, 'adj_high'] = bars.loc[mask, 'high'] / factor - dividend_per_share
bars.loc[mask, 'adj_low'] = bars.loc[mask, 'low'] / factor - dividend_per_share
```

如无除权则原始价=复权价，可跳过此步。

### 步骤2: 市场环境扫描（必做，为个股分析提供背景板）

**⚠️ 步骤2包含两层: 大盘环境(A-D) + 个股所属板块分析(E)。**
**不能只看大盘就跳到步骤3，必须运行sector_analysis.py分析个股所属板块。**

**目标**: 获取大盘+板块+北向资金数据，判断市场整体环境，为个股强弱判断提供基准。

**⚠️ 市场环境是所有个股分析的"背景板"——没有大盘和板块数据，个股分析就像没有参照物的孤立判断。**

**数据获取顺序（一次获取，所有个股共享）：**

#### A. 大盘指数（腾讯API批量请求）
```python
# 上证/深证/创业板/科创50 一次请求
codes = 'sh000001,sz399001,sz399006,sh000688'
url = f'https://qt.gtimg.cn/q={codes}'
# 解析: fields[1]=名称, fields[3]=现价, fields[32]=涨跌幅%, fields[37]=成交额(万)
```
记录: 每个指数的收盘价+涨跌幅+成交额
判断: 上证/深证/创业板是否同向 → 同向=共振，分歧=结构性行情

#### B. 北向资金（同花顺hsgtApi）
```python
url = "https://data.hexin.cn/market/hsgtApi/method/dayChart/"
# 返回 hgt(沪股通累计) + sgt(深股通累计)，单位亿元
# ⚠️ 返回的是从开盘累计到当前的净买入额
```
记录: 沪股通/深股通各自净流入/流出
判断: 外资态度 → 净流入>0偏多，净流出<0偏空

#### C. 概念板块涨幅TOP15 + 跌幅TOP5（东财API）
```python
# 概念板块涨幅TOP15
url = "https://push2.eastmoney.com/api/qt/clist/get?pn=1&pz=15&po=1&np=1&fields=f2,f3,f4,f12,f14,f104,f105&fid=f3&fs=m:90+t:3"
# 概念板块跌幅TOP5
url = "https://push2.eastmoney.com/api/qt/clist/get?pn=1&pz=5&po=0&np=1&fields=f2,f3,f4,f12,f14,f104,f105&fid=f3&fs=m:90+t:3"
```
记录: 每个板块的名称+涨跌幅+涨跌家数
判断: 今日市场主线是什么方向？资金在追什么？

#### D. 行业板块涨幅TOP10（东财API）
```python
url = "https://push2.eastmoney.com/api/qt/clist/get?pn=1&pz=10&po=1&np=1&fields=f2,f3,f4,f12,f14,f104,f105&fid=f3&fs=m:90+t:2"
```
记录: 行业板块涨跌排名
判断: 行业轮动方向

#### E. 个股所属板块分析（sector_analysis.py脚本）

⚠️ 这是步骤2的核心新增内容！不能只看大盘，必须分析个股所属板块。

```bash

python3 ~/.hermes/skills/mx-moni/scripts/sector_analysis.py <股票代码> [股票名称]
```

脚本输出:
  - 该股所属全部概念板块今日涨跌幅
  - 个股 vs 板块的相对强弱(强于/弱于/同步)
  - 板块近5日趋势(活跃/调整/震荡)
  - 同板块其他标的今日表现(横向对比)

⚠️ 单股分析(session)时必须运行此脚本，不能跳过。

**⚠️ 获取个股完整概念列表的备用API**:

**市场环境输出模板（放在分析报告最前面）：**

```
━━ 一、市场环境 ━━

大盘指数:
  上证: XXXX.XX +X.XX%  成交XXXX亿
  深证: XXXX.XX +X.XX%  成交XXXX亿
  创业板: XXXX.XX +X.XX%  成交XXXX亿
  判断: [共振上行/结构性行情/分化震荡/普跌]

北向资金: 合计XX亿 [净流入/净流出]
  沪股通: XX亿  深股通: XX亿

今日主线(概念TOP5):
  1. XXX +X.XX%
  2. XXX +X.XX%
  ...

个股所属板块分析(sector_analysis.py):
  板块A: +X.XX%  个股: +X.XX%  → [强于/弱于/同步]板块
  板块B: +X.XX%  个股: +X.XX%  → [强于/弱于/同步]板块
  板块趋势: [近5日活跃/调整/震荡]
  同板块对比: 标的一+X.XX% / 标的二+X.XX%

市场定性: [一句话总结今日市场环境对个股的影响]
```

**⚠️ 市场环境对个股分析的影响规则：**

| 大盘环境 | 板块表现 | 个股表现 | 综合判断 |
|---------|---------|---------|---------|
| 强(>1%) | 强(>板块) | 强(>板块) | 🟢 独立强势，最优 |
| 强(>1%) | 强 | 弱(<板块) | 🟡 跟风但弱于板块，注意 |
| 弱(<-1%) | 弱 | 强(逆势) | 🟢 独立强势，但需确认持续性 |
| 弱(<-1%) | 弱 | 弱 | 🔴 系统性风险，回避 |
| 平(<1%) | 平 | 强 | 🟡 可能有独立催化，关注 |

**操作影响：**
- 大盘强+板块强 → 个股分析偏乐观，可适当放宽标准
- 大盘弱+板块弱 → 个股分析偏保守，收紧止损
- 大盘强+板块弱 → 板块轮动可能不在这个方向，谨慎
- 大盘弱+板块强 → 独立行情，但需警惕补跌

**⚠️ V3.1红灯板块过滤(2026-08-04用户要求改进):**
用户原话: "红灯期间完全不操作我觉得不太合适"
当大盘红灯时，market_environment.py会检测系统性风险并启用板块过滤：
- 系统性风险(三指数均跌破MA20+MA20斜率<-0.3%+创业板偏离<-5%) → 标记为高风险
  - V3.1改进: 即使系统性风险,也允许板块检查(因为可能是板块轮动导致)
  - 个股板块相对强度>+0.5% → 板块独立强,正常仓位(100%)
  - 板块相对强度-0.5%~+0.5% → 板块中性偏强,仓位减半(50%)
  - 板块相对强度<-0.5% → 板块偏弱,维持禁止
- 非系统性风险(分化行情) → 启用板块过滤(同上)
V3.0→V3.1核心改变: 红灯期间从"完全禁止"改为"板块强+三要素满足即可操作"

### 步骤3: 量价关系分析（核心，第一优先）

**⚠️ 单股深度分析(session)时，必须用本skill的K线规则手动检查近3-5日组合形态，不能只依赖scan_candidate.py的输出。scan_candidate.py V4.2已支持3日组合形态检测(双针探底/十字星确认/看涨吞没等)，但单股分析需要更精细的手动判断(如验证形态的严格条件、检查信号是否已被后续K线确认/失效)。**

**目标**: 通过逐日K线+成交量判断主力处于什么阶段

**主力行为4阶段识别框架**:

| 阶段 | 量价特征 | 典型K线 |
|------|---------|--------|
| 建仓期 | 缩量阴跌后放量阳线；底部温和放量价不跌 | 底部长下影阳线 |
| 洗盘期 | 缩量回调（量缩价不跌）；地量出现=洗盘尾声 | 缩量十字星 |
| 拉升期 | 温和放量上涨（量价齐升）；放量突破平台 | 放量中阳线 |
| 出货期 | 天量天价；放量下跌；冲高回落上影线长 | 高位大阴线 |

**⚠️ 每个判断必须附带具体K线实例**:
- 日期 + 开/收/高/低
- 成交量 + 与前日对比(放大/缩小百分比)
- 为什么这根K线说明主力在做X

**量价背离（趋势拐点预警）**:
- 顶背离：价格创新高但成交量未创新高 → 见顶信号
- 底背离：价格创新低但成交量未创新低 → 见底信号

**量价评分**: 1-5分
- 5分: 底部放量建仓+量价同步上涨
- 4分: 缩量企稳+温和放量反弹
- 3分: 量价中性，无明确信号
- 2分: 有出货迹象但未完全确认
- 1分: 天量天价/放量暴跌/量价全面恶化

### 步骤4: 资金流向验证

**目标**: 用资金流数字验证量价判断是否准确

- 主力资金连续净流入 → 印证建仓/拉升判断
- 主力资金连续净流出 → 印证出货判断
- 量价说建仓但资金在流出 → 判断可能有误，需重新审视

**关键规则**: 资金流是辅助验证，量价才是主力真实意图

**⚠️ 资金流数据完全不可用时的处理 (2026-07-23蓝思科技案例)**:

当em_api.py持续限频(3次重试仍失败,间隔8s→12s→20s)时:
1. 量价关系权重从30%提升至40%,资金面从20%降至10%
2. 资金面维度得分固定为2.0/5(保守中性,不因缺失给极端分)
3. 用历史报告中的资金流数据作为"估算参考"(标注为"历史数据")
4. 报告中必须标注: "⚠️ 资金流数据缺失(东财API限频),量价判断未经资金流验证"
5. 综合评分上限降至70分(数据不完整时不应给出高确信判断)

**⚠️ 任务context中已有K线/行情数据时**:

当任务context中已提供近期K线数据(如"近5日K线"表格)或实时行情时,直接使用该数据进行分析,不要再通过curl/API重新获取。只在需要更长时间范围(如30日/60日均线计算)时才尝试API补充。

### 步骤5: 技术面+均线系统

**均线多空排列判断**:
- 多头排列: MA5>MA10>MA20>MA30 → 趋势向上
- 空头排列: MA5<MA10<MA20<MA30 → 趋势向下
- 纠缠态: 均线交叉缠绕 → 方向不明

**关键技术指标**:
- MACD: 金叉/死叉、零轴上下
- RSI: 超买(>70)/超卖(<30)
- 量比: >2放量 / <0.5缩量
- 换手率: >10%异常活跃 / <1%冷门

### 步骤6: 情绪周期分析

**核心哲学**: 市场参与者的情绪在"恐慌→悲观→怀疑→希望→乐观→兴奋→贪婪→狂热"之间循环。聪明钱在恐慌底部布局，在狂热顶部离场。

**换手率量化指标**:
| 换手率 | 情绪阶段 | 操作含义 |
|--------|---------|---------|
| < 0.5%/日 | 冷淡底部 | 潜在底部区域，贪婪时买入别人的恐慌 |
| 0.5%-2% | 正常平稳 | 情绪中性，观望为主 |
| 2%-5% | 活跃升温 | 市场开始关注，不宜追高 |
| 5%-10% | 过热警惕 | 游资/散户涌入，警惕情绪顶 |
| > 10% | 极度过热 | 通常为短期顶部 |

**连续换手率走势分析**:
- 由高向低(持续降温)+成交量萎缩 → 情绪退潮，耐心等待
- 由低向高(加速升温)+成交量陡增 → 情绪启动，可介入
- 突然单日暴量(换手率超过前期5倍) → 往往是主力出货，需警惕

**情绪底部特征（满足3项以上=买入区）**:
- [ ] 近20日换手率处于近一年低位
- [ ] 成交量持续萎缩，低于近60日均量50%以上
- [ ] 近期新闻以低调、中性或负面为主
- [ ] 股价在MA20附近或以下，但未出现恐慌性暴跌
- [ ] 机构持仓稳定或小幅增加

**情绪顶部特征（满足3项以上=减仓区）**:
- [ ] 近5日换手率 > 近20日均值的2倍
- [ ] 成交量脉冲式放大（单日）
- [ ] 新闻以利好兑现、机构目标价大幅上调、散户追捧为主
- [ ] 股价偏离MA5超过8%（高乖离率）
- [ ] MACD出现顶背离

**评分调整**:
- 情绪底部满足3项以上 → +10分
- 情绪底部满足全部5项 → +15分
- 情绪顶部满足3项以上 → -10分
- 情绪顶部满足全部5项 → -15分

### 步骤7: 估值+基本面

**估值检查**:
- PE(TTM) vs 行业均值
- PB vs 每股净资产
- PEG = PE / 净利润增速(%) → <1便宜 / 1-1.5合理 / >1.5贵
- 前向PE = 当前价 / 机构一致预期EPS

**预期差分析（V2.2新增）**:

预期差 = 市场预期 vs 实际情况 的偏差。聪明钱赚的是预期差的钱。

| 预期差类型 | 判断方法 | 操作含义 |
|-----------|---------|---------|
| 预期修复 | PE < 行业均值×0.7 且 基本面改善 | 🟢 估值便宜+基本面好转=买入机会 |
| 预期过热 | PE > 行业均值×1.5 且 机构一致上调 | 🔴 估值泡沫+过度乐观=风险区 |
| 预期落空 | 业绩不及预期 或 政策低于预期 | 🔴 利好出尽=卖出信号 |
| 预期差修复 | 实际业绩 > 市场一致预期 | 🟢 超预期=股价重估动力 |

**预期差量化指标**:
```
后向PE = 当前价 / 过去12个月EPS(已知)
前向PE = 当前价 / 机构一致预期EPS(未来12个月)
预期差 = 后向PE / 前向PE

判断:
  预期差 > 1.3 → 市场预期未来业绩大幅增长(成长股特征)
  预期差 1.0-1.3 → 市场预期温和增长(正常)
  预期差 < 1.0 → 市场预期未来业绩下滑(警惕)
```

**操作规则**:
- 预期修复 + 量价配合 → 加分(安全边际+催化剂)
- 预期过热 + 放量滞涨 → 减分(泡沫风险)
- 机构一致预期大幅上调 + 股价未反应 → 潜在机会
- 机构一致预期大幅下调 + 股价已反应 → 风险释放

**基本面关注**:
- 净利润增速（同比）
- ROE水平
- 机构覆盖度（有无近期研报）
- 机构一致预期EPS

### 步骤8: 概念板块完整映射（必做，不可跳过）

**目标**: 查清个股的完整概念归属，为后续对比分析提供基础

**操作**:
1. 获取个股全部概念标签(同花顺reason / 东财概念板块eastmoney_concept_blocks())
2. 特别标注近期市场热门概念是否在列表中
3. 区分"核心概念"(有真实业务) vs "蹭概念"(无实质业务)
4. 记录概念纯度评级(★★★~★★★★★)

**⚠️ 常见错误**: 只取最显眼的一个概念就下结论
→ 协鑫能科案例: 遗漏"算电协同"核心战略，只标"抽水蓄能"，
导致对比分析结论严重偏差。必须获取完整概念列表。

**龙头识别框架（V2.2新增）**:

板块龙头 = 在板块启动周期中率先上涨、辨识度最高的标的。

**龙头5项识别条件（满足3项以上=龙头）**:
- [ ] 板块涨幅排名第1 或 个股涨幅>板块涨幅×2
- [ ] 换手率 > 5%（龙头换手率通常高于板块均值）
- [ ] 量比 > 1.5（有活跃的交易兴趣）
- [ ] 率先涨停或大涨（板块内第一个异动）
- [ ] 有明确的催化逻辑（中标/政策/业绩/国企改革等）

**龙头在评分中的处理**:
- 确认为龙头 → 评分额外+5分（龙头溢价）
- 龙头可适当放宽标准（原则7：龙头放宽）
  · 缩量比阈值可放宽至1.0（正常是0.8）
  · MA20偏离容忍度放宽至10%（正常是5%）
  · 但必须有明确的催化逻辑支撑

**龙头 vs 蹭概念 区分**:
| 维度 | 真龙头 | 蹭概念 |
|------|--------|--------|
| 营收占比 | 核心业务营收>30% | 该概念营收<5% |
| 机构覆盖 | 有券商研报覆盖 | 无机构覆盖 |
| 涨停性质 | 一字板/缩量涨停(筹码锁定) | 开板放量涨停(游资进出) |
| 催化逻辑 | 有实质催化(中标/政策/业绩) | 纯概念炒作无催化 |
| 辨识度 | 板块内公认第一 | 需要解释才能关联 |

**⚠️ 常见错误**: 把蹭概念的票当龙头追高
→ 海立股份案例: 东财概念标签有"光刻机"，但实际营收99.997%来自空调压缩机，
光刻机业务占比<0.003%。市场炒的是"借壳预期"，但已被公司多次否认。

### 步骤9: 消息面+事件驱动+风险筛查

**消息面情绪打分**:
- 利好/利空条数统计
- 关键新闻重要性评估
- 消息面总情绪: 偏多/中性/偏空 + 得分

**事件驱动分类框架（V2.2新增）**:

| 事件类型 | 识别信号 | 影响路径 | 兑现概率 |
|---------|---------|---------|---------|
| 业绩类 | 业绩预告/快报/年报 | 基本面改善→估值重估 | 高(已公告) |
| 政策类 | 国务院/部委政策文件 | 行业景气→订单预期 | 中(需落地) |
| 订单类 | 中标公告/合同签署 | 营收确认→业绩贡献 | 高(已签约) |
| 并购类 | 重组/收购公告 | 协同效应→估值重塑 | 低(不确定性大) |
| 监管类 | 处罚/立案/问询 | 合规风险→估值折价 | 高(已发生) |

**利好兑现出货识别（硬规则）**:
- 利好发布当天收盘=全天最高 + 次日成交量创近期新高
  → 自动触发"利好兑现=见顶"标记
  → 量价维度评分降至2/10以下
  → 不因利好消息提高评分

**事件影响评估**:
1. 事件是短期交易催化还是长期基本面改善?
2. 事件是否已被市场预期(price in)?
3. 事件的兑现时间线(立即/3个月/1年)?
4. 同板块其他标的是否同步反应?

**风险筛查（RiskAgent模式）**:
必须检查的风险项:
- [ ] 大股东减持/质押
- [ ] 业绩预亏/变脸
- [ ] 监管处罚/立案调查
- [ ] 行业政策利空
- [ ] 限售解禁（30天内）
- [ ] 估值异常（PE>100或为负、PB>10）
- [ ] 技术破位（死叉、跌破关键支撑）

**风险分级**:
- high: 重大风险（造假/诉讼/大规模减持）→ 一票否决
- medium: 显著风险（业绩不及预期/解禁/板块利空）→ 降级信号
- low: 轻微风险（分析师下调/小额减持）→ 记录但不阻断

## 三、决策评分体系

### 综合评分权重
| 维度 | 权重 | 说明 |
|------|------|------|
| 量价关系 | 30% | 主力行为阶段+量价评分 |
| 技术面 | 25% | 均线排列+趋势强度+关键位 |
| 资金面 | 20% | 主力资金流向验证 |
| 消息面 | 15% | 情绪+催化+风险 |
| 估值面 | 10% | PE/PEG/基本面安全边际 |

**⚠️ 步骤3量价评分(X/5)换算为0-100分: 量价维度得分 = 量价评分×20 (如4/5=80分, 3/5=60分)**

**⚠️ 市场状态动态权重调整（V2.2新增）**:

根据大盘MA20斜率判断当前市场状态,动态调整各维度权重:

| 市场状态 | 判断标准 | 量价 | 技术 | 资金 | 消息 | 估值 |
|---------|---------|------|------|------|------|------|
| **trending_up** | 上证MA20斜率>0.1%且站上MA20 | 25% | **30%** | 20% | 15% | 10% |
| **trending_down** | 上证MA20斜率<-0.1%且跌破MA20 | 30% | 20% | 20% | 15% | **15%** |
| **sideways** | MA20斜率在±0.1%之间 | **35%** | 25% | 20% | 10% | 10% |
| **volatile** | 近5日振幅>3%且方向不明 | 30% | 25% | **25%** | 10% | 10% |

**调整逻辑**:
- trending_up: 技术面权重最高(趋势跟踪)
- trending_down: 估值面权重提高(寻找安全边际)
- sideways: 量价权重最高(波段操作靠量价)
- volatile: 资金面权重提高(资金流向决定方向)

**⚠️ 资金流数据缺失时的权重重分配** (2026-07-23确立):
当em_api.py限频导致资金流数据完全不可用时,权重重分配:
| 维度 | 正常权重 | 缺资金流时权重 |
|------|---------|--------------|
| 量价关系 | 30% | **40%** |
| 技术面 | 25% | 25% |
| 资金面 | 20% | **10%** |
| 消息面 | 15% | 15% |
| 估值面 | 10% | 10% |
综合评分上限降至70分(数据不完整=不给高确信判断)。

### 评分→操作映射
- 80-100分: 🟢 买入/加仓（条件全满足，高确信）
- 60-79分:  🟢 买入/加仓（多数积极，小瑕疵）
- 40-59分:  🟡 持有/观望（信号混合或有风险）
- 20-39分:  🔴 卖出/减仓（趋势偏空+风险）
- 0-19分:   🔴 卖出/止损（高风险+看空）

### 操作性护栏（Actionability Guardrails）
- **不因单日涨跌在买/卖之间反复跳** — 至少观察2-3日确认趋势
- **买入需支撑位确认** — 或有效突破阻力位+量能/资金流验证
- **卖出需破支撑** — 或主力持续出逃、风险明显升高
- **价格在支撑与阻力之间且资金流不明** → 偏好中性操作(hold/watch)
- **高风险一票否决** — 任何high级风险直接降为卖出
- **⚠️ 超跌修正(2026-07-21新增)**: 累计跌幅>30%时,评分自动加10-15分缓冲(防止极度看空);评分震荡>30分时禁止极端方向判断(80+或<20)
- **⚠️ 板块联动修正(2026-07-21新增)**: 多只同板块票同时涨停/跌停时,必须排查板块级催化再下结论

## 四、标准分析输出模板

10. 附录: 完整K线数据
