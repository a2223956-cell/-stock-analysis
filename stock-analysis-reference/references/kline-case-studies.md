### 核心教训

1. **天量天价是铁律**: 6/29天量2449万手+股价新高=见顶信号
2. **上影线是警告**: 高位频繁出现长上影线，显示主力在出货
3. **缩量下跌确认出货**: 7/1-7/6成交量逐步萎缩，说明主力已出大部分货
4. **PE极高需警惕**: 166倍PE属于概念炒作估值，热度退潮后必然回归

## 通用量价模式速查

### 天量见顶模式
```
信号: 股价创新高 + 成交量创历史新高 + 换手率>15%
后续: 连续放量暴跌(3-5天) → 缩量阴跌 → 筑底
操作: 天量当天或次日必须减仓
```

### 缩量涨停模式
```
信号: 涨停 + 成交量较前日缩小30%+
含义: 惜售明显，主力控盘
后续: 可能继续拉升，但需观察次日量能
```

### 放量暴跌模式
```
信号: 大阴线(跌幅>5%) + 成交量较前日放大50%+
含义: 主力出货，恐慌性抛售
后续: 继续下跌概率大，反弹即减仓
```

### 缩量企稳模式
```
信号: 连续下跌后 + 成交量较峰值缩50%+ + 跌幅收窄
含义: 卖压枯竭，可能筑底
操作: 观望，等待放量阳线确认反转
```
