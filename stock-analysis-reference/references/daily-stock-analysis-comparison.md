## 架构差异

| 维度 | daily_stock_analysis | 我们的a-stock-data |
|------|---------------------|-------------------|
| 分析方式 | 多Agent协作(5个专业Agent) | 子代理委托(delegate_task) |
| 策略系统 | 16个可插拔YAML策略 | 量价关系+加仓信号5项检查 |
| 决策权重 | 技术40%+情报30%+风险30% | 量价优先→资金验证→估值→消息 |
| 风险机制 | soft/hard两级，hard一票否决 | 高风险直接降级 |
| 大盘分析 | 有(CN/HK/US三段式复盘) | 无(仅个股) |

## 它有的我们缺的（可借鉴）

1. **情绪周期策略** — 逆情绪布局，恐慌底买入，狂热顶卖出
   - 核心: 换手率极低+缩量=恐慌底；换手率极高+天量=狂热顶
   - 我们的量价分析有类似逻辑但没独立成策略

2. **缠论/波浪理论** — 高级形态分析
   - 分型→笔→线段→中枢→趋势
   - 5浪推动+3浪调整
   - 我们目前只用均线+量价，缺形态识别

3. **龙头策略** — 板块轮动中识别领涨股
   - 需要板块排名数据(同花顺热点reason已部分覆盖)

4. **筹码分布分析** — chip distribution
   - 判断套牢盘/获利盘比例
   - 我们没有这个维度

5. **大盘级复盘** — 不只看个股，先看指数方向
   - A股: 上证/深证/创业板同向性 + 成交额 + 板块轮动
   - 我们直接跳到个股分析

6. **事件驱动策略** — 业绩/政策/并购等催化评估
   - 我们的新闻分析是情绪打分，不是催化强度评估

## 我们有的它缺的

1. 深度量价关系解读(逐K线分析主力行为阶段+K线实例)
2. 新闻情绪量化打分(5源聚合+情绪得分)
3. 东财妙想搜索集成
4. 子代理并行分析(多票同时跑)
5. 机构一致预期EPS预测(akshare stock_profit_forecast_ths)
6. 编造数据点的一票否决(pitfall)

## 核心交易理念(7条) — 可参考

1. 严进策略 — 乖离率<5%才入场，不追高
2. 趋势交易 — MA5>MA10>MA20多头排列
3. 效率优先 — 关注筹码结构好的股票
4. 买点偏好 — MA5/MA10附近回踩买入
5. 风险排查 — 利空新闻一票否决
6. 量价配合 — 成交量验证价格运动
7. 强势趋势股放宽 — 龙头股可适当放宽标准

## 决策Agent信号权重(可参考)

- 技术面 ~40%
- 情报面 ~30%
- 风险面 ~30%(高风险一票否决)
- 策略评估 ~20%(如有则挤占其他)
- 评分: 80-100买入 / 60-79买入 / 40-59持有 / 20-39卖出 / 0-19卖出

## 评分体系关键规则

- 不因单日涨跌在买/卖之间反复跳
- 买入需支撑位确认或有效突破+量能验证
- 卖出需破支撑、主力持续出逃或风险升高
- 价格在支撑阻力间且资金流不明→偏好中性操作
