# 板块横向对比 — 6维度框架

> 用于同板块/同概念多只股票的横向对比分析，找出板块内最强/最弱标的。

## 适用场景

- 用户持仓股在板块内表现差异明显时
- 需要判断"同板块该持有哪只"时
- 板块轮动分析、资金选择差异归因

## 6维度对比框架

### 维度①: 趋势强度
- 近20日/30日涨跌幅
- 当前价格在区间中的位置(0%=最低, 100%=最高)
- 均线排列方向(多头/空头/交叉)

### 维度②: 资金流向
- 近5-10日主力累计净流入/流出(亿元)
- 关键日资金异动(单日>3亿为显著)
- 主力建仓 vs 出货信号

### 维度③: 估值安全
- PE(TTM)对比
- PB对比
- 特殊情况: 亏损股(PE负)的"困境反转"逻辑
- 定增/增发等股本摊薄因素

### 维度④: 技术形态
- K线关键形态(涨停/长上影/长下影/十字星)
- 支撑/压力位有效性
- 量价配合度

### 维度⑤: 概念催化
- 概念数量和纯度
- 催化剂时效性(已兑现 vs 待兑现)
- 国企改革/政策加持等额外催化

### 维度⑥: 主力行为
- 主力资金连续N日流向趋势
- 拉升/出货/建仓阶段判断
- 游资偏好(低价股、国企股更受青睐)

## 对比输出格式

```
| 维度 | 股票A | 股票B | 股票C | 胜出 |
|------|-------|-------|-------|------|
| ①趋势 | 描述 | 描述 | 描述 | 谁 |
| ②资金 | ... | ... | ... | 谁 |
| ... | ... | ... | ... | ... |
| 综合 | N/6 | N/6 | N/6 | 总结 |
```

## 走势差异归因分析

找出核心差异原因(通常3-6个)，按影响力排序:
1. **催化剂差异** — 国企改革/政策/业绩等独有催化
2. **资金选择差异** — 游资偏好低价股、主力选择不同标的
3. **估值压力差异** — PE过高是最大负担
4. **技术面差异** — 多头排列vs空头排列的正/负反馈
5. **主力行为差异** — 建仓vs出货阶段不同
6. **概念纯度差异** — 纯概念股 vs 多元化业务

## Pitfalls

- 不要只看当日涨跌，要对比多日趋势
- 亏损股(PE负)不能简单用PE排序，需看"困境反转"逻辑
- 低价股天然更容易被游资炒作，这是结构性优势而非基本面优势
- 资金流向的绝对值需考虑市值差异，用占比(%)辅助判断
