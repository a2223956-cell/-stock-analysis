# 三重底 vs 双顶 对比分析案例(2026-07-30)

## 概述

2026-07-30同一会话中分析了5只股票,其中3只展现了明确的底部/顶部形态,
提供了三重底(确认vs未确认)和双顶(确认)的完美教学对比。

## 案例1: 泛微网络(603039) — 三重底确认 ✅

### 形态数据
- 第一底: 7/20 low=28.25, close=28.89
- 第二底: 7/21 low=28.31, close=29.86
- 第三底: 7/27 low=28.10, close=29.28
- 三次低点极差: 0.7%(28.10-28.31)
- 颈线位: 30.18-30.20(7/22高点)

### 5项检查
1. ✅ 三次低点接近(极差0.7%<3%)
2. ✅ 每次都被拉回(收盘>最低价)
3. ✅ 第三次后放量阳线(7/28-7/29)
4. ✅ 颈线位30.18已突破(7/29收盘30.93)
5. ✅ 成交量底部极度萎缩(58K)后放大

→ 5/5全部满足! 标准三重底!

### 理论目标
颈线位30.20 + (30.20-28.22) = 32.18
7/30盘中已突破至33.16,目标达成+3.6%!

### 操作
- 已持有: 继续持有,目标上移至34.74-36.31
- 未持有: 不追高,等回调至32.18-33.00
- 止损: 32.18(原目标变支撑)

### 评分
- 7/29: 85分(强烈偏多)
- 7/30盘中更新: 90分(目标达成+放量确认)

## 案例2: 双环传动(002472) — 三重底未确认 ❌

### 形态数据
- 第一底: 7/20 low=35.00
- 第二底: 7/24 low=35.08
- 第三底: 7/29 low=35.01
- 三次低点极差: 0.23%(35.00-35.08)
- 颈线位: 38.67(7/20高点)

### 5项检查
1. ✅ 三次低点接近(极差0.23%<3%)
2. ✅ 每次都被拉回(收盘>最低价)
3. ❌ 第三次后无放量阳线(7/30下跌-1.24%)
4. ❌ 颈线位38.67未突破(当前35.75,距颈线+8.2%)
5. ❌ 成交量未明显放大

→ 仅2/5满足! 形态未确认!

### 关键差异( vs 泛微网络)
- 极差更小(0.23% vs 0.7%)看似更好,但颈线未突破=无意义
- 泛微网络颈线30.18已突破 → 确认
- 双环传动颈线38.67远未突破 → 未确认
- → "跌三次都跌不破"≠"可以买",还需"涨上去突破颈线"

### 操作
- 不确认 = 不操作
- 等待: 放量突破38.67 + 资金连续流入
- 当前: 观望

### 评分
- 33分(不推荐)

## 案例3: 雷赛智能(002979) — 双顶确认 🔴

### 形态数据
- 双顶1: 7/23 high=61.58
- 双顶2: 7/27 high=61.13
- 两个高点差距: 0.7%
- 颈线位: 55.95(7/29低点)

### 5项检查
1. ✅ 两个高点接近(差距0.7%<2%)
2. ✅ 第二个高点量能萎缩(161K<190K=量价背离)
3. ✅ 跌破颈线位55.95(7/30收盘53.04)
4. ✅ 收盘价53.04<颈线55.95
5. ✅ 跌破后继续下跌(7/30暴跌-8.00%)

→ 5/5全部满足! 标准双顶!

### 理论目标
颈线位55.95 - (61.58-55.95) = 50.32
从当前53.04到目标: -5.1%

### 操作
- 已持有: 止损!反弹至55.95减仓,跌破51.18清仓
- 未持有: 绝对不抄底
- 目标: 50.32

### 评分
- 23分(止损)

## 核心教训

1. **极差小≠形态好**: 双环传动极差0.23%比泛微网络0.7%更小,但颈线未突破=无意义
2. **颈线突破是关键**: 三重底必须向上突破颈线才算确认,双顶必须向下跌破颈线才算确认
3. **确认度决定操作**: 5/5确认=操作,2/5未确认=观望,完全相反
4. **同一形态相反结果**: 泛微网络三重底确认→+7.21%,双环传动三重底未确认→-1.24%
5. **双顶是最危险信号**: 雷赛智能双顶确认→暴跌-8.00%,必须止损

## 教学方法

当用户问"X是不是Y形态"时:
1. 列出形态的5项检查条件
2. 逐项✅/❌判定(必须用实际K线数据)
3. 统计满足数
4. 特别检查"颈线位是否突破"
5. 给出结论: 已确认/形成中/不构成
6. 如果可能,找一个已确认的同类形态做对比
