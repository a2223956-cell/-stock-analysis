## 一、超跌反弹修正规则

### 问题
分析框架在个股暴跌30-40%+后仍然给出极低评分,严重低估超跌反弹爆发力。

### 案例
| 股票 | 从高点跌幅 | 评分 | 次日表现 |
|------|-----------|------|---------|
| 深科技 | -42.9% | 0.68分 | 涨停+9.99% |
| 凯盛科技 | -45% | 0.89分 | 涨停+9.99% |
| 通富微电 | -25.6%(3天) | 18.5分 | 涨停+10% |

### 根因
1. "主力出货完成=不会涨"逻辑有缺陷 → 新主力可低位建仓
2. 跌幅>30-40%时技术性反弹概率被系统性低估
3. 板块系统性催化被忽略
4. PE估值框架在板块行情中暂时失效

### 硬规则
```
暴跌后评分检查清单:
  ① 累计跌幅>30%? → 自动进入"超跌区间",评分+10-15分缓冲
  ② 多只同板块票同时涨停? → 排查板块级催化
  ③ 主力出货完成度>80%? → 从"看空"调为"中性"
  ④ KDJ-J值<0或RSI<25? → 超卖信号权重提升
  ⑤ 评分震荡>30分(1周内)? → 禁止极端方向判断
```

## 八、中继平台评分陷阱(2026-07-22 协鑫能科案例)

### 问题
协鑫能科6/30报告给出68分(谨慎乐观),建议"分批建仓",但股价随后从16.30跌至12.97(-20.4%)。报告将"中继平台"误判为"筑底整理中后期"。

### 根因
评分框架在"缩量横盘"阶段给了过高评分:
1. "极度缩量"(33万手地量)被解读为"抛压枯竭" → 加分
2. "横盘不破前低"(15.68守住)被解读为"支撑有效" → 加分
3. 但资金流仍在净流出(20日累计-6.52亿) → 被忽略
4. "横盘"仅维持2周(<10天) → 不够构成真正底部

### 与双环传动案例的区别
- 双环传动7/14报告: 评分25分(偏空),7/17暴跌-9%验证 → 判断偏保守但方向对
- 协鑫能科6/30报告: 评分68分(偏多),但随后跌-20.4% → 判断方向完全错误,误导性更强

### 硬规则: 中继平台评分修正

当个股暴跌后出现"缩量横盘"时,评分必须额外检查以下5项。**全部满足才可给≥60分**:

```
中继平台风险检查清单:
  ① 资金流: 横盘期资金是否转为连续3日+净流入?
     → 仍为净流出 → 扣10-15分(不是底部,是抛压减轻)
  ② 横盘时间: 是否≥15个交易日?
     → <10天 → 扣10分(时间不够,可能是中继平台)
     → 10-15天 → 扣5分(需进一步观察)
  ③ 低点是否抬高: 横盘期间最低价是否逐步走高?
     → 低点下移(破前低) → 扣15分(中继平台确认)
  ④ 均线方向: MA20是否仍在下降?
     → MA20下降 → 扣5分(趋势未反转)
  ⑤ 板块对比: 个股是否弱于所属板块?
     → 弱于板块 → 扣5分(个股层面问题)
```

### 评分调整示例

协鑫能科6/30:
  原始评分: 68分
  检查: ①资金仍流出(-1.52亿)扣-15 ②横盘仅2周扣-10 ③MA20下降扣-5 ④弱于板块扣-5
  调整后: 68-35=33分 → 🔴 观望不建仓(不是"可建仓"!)

### 操作规则
评分调整后:
- 33-40分: 🔴 观望不建仓,等待更多底部确认信号
- 40-50分: 🟡 可小仓位试探(≤10%),但必须有止损
- 50-60分: 🟡 持有观察,不加仓
- 60+分: 🟢 可建仓(前提是资金流已转正)

### 关键教训
"极度缩量"≠底部信号。缩量只说明抛压减轻,不说明买盘进场。
真正的底部需要四要素同时满足: 缩量 + 资金连续流入 + 均线走平 + 时间足够(≥15天)

## 九、放量滞涨识别(2026-07-24 中国西电案例)

### 问题
中国西电7/23涨停(+10%)后,7/24高开冲高14.48后持续回落,成交量创近期新高(314万手,换手6.12%)但价格仅涨+0.51%→收盘几乎平盘。这是典型的"放量滞涨"出货信号。

### 定义
**放量滞涨 = 成交量显著放大(>前日×1.5) + 价格未能有效上涨(涨幅<1%或收阴)**

### 识别条件(满足2条以上即确认)
1. 当日成交量>前日×1.5 或创近5日新高
2. 价格涨幅<1% 或 收盘<开盘(阴线)
3. 上影线长度>实体×2(冲高回落)
4. 换手率>近期均值×2
5. 大盘/板块下跌但个股也跟随走弱(非独立行情)

### 与普通回调的区别
- 普通回调: 缩量下跌(量<前日×0.8) → 正常获利回吐
- 放量滞涨: 天量+价格不涨 → 主力在大量出货

### 操作规则
- 涨停次日出现放量滞涨 → 确认出货,应减仓
- 高位(涨幅>30%+)出现放量滞涨 → 见顶信号,考虑清仓
- 底部区域出现放量滞涨 → 可能是换手(需结合资金流判断)

### 案例
中国西电7/24: 开14.01→高14.48→收13.72(+0.51%),量314万手(换手6.12%)
→ 上影0.76元/下影0.07元=10.9倍 → 确认放量滞涨出货

## 十、连续分析限频应对(2026-07-24实战)

### 问题
连续委托4只票(许继/西电/雷赛/百利天恒)分析时,em_api.py在第2只票后触发限频,导致后3只票全部资金流数据缺失。

### 根因
东财push2his按IP限频,短时间4只票×多个API调用=15+次请求,约2分钟后触发。

### 解决方案(降级链路)
```
1. em_api.py fund_flow → 成功则用
2. em_api.py 3次失败(间隔8s→12s→20s) → 妙想mx-data "XX股票主力资金流向"
3. mx-data也失败 → 跳过资金流,量价权重提至40%,评分上限降至70分
```

### 预防措施
- 批量分析(3+只票)时,每只票的API调用间sleep(10-15秒)
- 先用腾讯API批量获取所有票的K线/行情(不受限频影响)
- 资金流查询放到最后,用mx-data作为主要数据源(不受push2his限频)
- em_api.py仅用于获取push2his独有的数据(如分时资金流)

## 十二、涨停后走势分化诊断框架(2026-07-28跨票对比)

### 问题
7/16-7/23期间,福蓉科技/许继电气/中国西电三票都出现"涨停+次日上影线"形态,但后续走势截然不同:
- 福蓉科技: 涨停→上影线→连续反弹(+6.5%) 🟢 洗盘
- 许继电气: 涨停→上影线→连续暴跌(-6.4%) 🔴 出货
- 中国西电: 涨停→上影线→暴跌(-4.19%) 🔴 出货

仅看K线形态(涨停+上影线)无法区分,必须用5大维度交叉验证。

### 涨停后走势分化5大诊断维度

| 维度 | 洗盘信号(看涨) | 出货信号(看跌) |
|------|---------------|---------------|
| ① 涨停日量能 | 缩量涨停(量<均量×70%)=筹码锁定 | 放量涨停(量>均量×100%)=跟风盘涌入 |
| ② 涨停前涨幅 | 低位涨停(此前下跌>10%)=底部反转 | 高位涨停(此前上涨>20%)=拉高出货 |
| ③ 涨停后资金 | 涨停日+次日资金净流入为正 | 涨停日+次日资金净流入为负(一日游) |
| ④ 后续K线 | 3日内收复涨停价=洗盘确认 | 3日内跌破涨停价=出货确认 |
| ⑤ 大盘对比 | 大盘跌时个股逆势强=独立催化 | 大盘跌时个股更弱=系统性抛压 |

### 实战案例对比

```
指标            福蓉科技(洗盘✅)  许继电气(出货❌)  中国西电(出货❌)
──────────────────────────────────────────────────────────────
涨停日量能      缩量(57%均量)    放量(108%均量)   放量(+21%均量)
涨停前涨幅      -10.2%(低位)     +9.3%(反弹高位)  +16.5%(反弹高位)
涨停+次日资金   +0.63亿(净流入)  +0.03亿(几乎持平) +0.37亿(微正)
后续是否收复    ✅7/22收复8.57   ❌从未收复23.08  ❌从未收复13.65
大盘对比        逆势+1.14%       弱于大盘-1.84%   弱于大盘-4.19%
综合判断        🟢洗盘           🔴出货           🔴出货
```

### 诊断评分规则

5大维度逐项打分(+1看涨/-1看跌):
- 4-5分: 🟢 洗盘概率高, 可持有/低吸
- 2-3分: 🟡 信号混合, 等待确认
- 0-1分: 🔴 出货概率高, 应减仓/回避

### 关键教训

1. **涨停日量能是第一判断维度**: 缩量涨停=筹码锁定(主力控盘), 放量涨停=跟风盘涌入(主力借势出货)
2. **涨停前位置决定含义**: 底部涨停=反转信号, 高位涨停=诱多信号
3. **后续是否收复涨停价是确认信号**: 3日内收复=洗盘确认, 3日内跌破=出货确认
4. **不能只看单票K线形态**: 必须横向对比同板块其他标的+大盘环境
5. **资金流是验证维度不是判断维度**: 量价关系(维度关系(维度①②④)才是主力真实意图
