## 二、策略二: 涨停洗盘后主升浪

### 核心逻辑

涨停 → 洗盘(清理浮筹+推高散户成本) → 整理 → 突破确认 → 主升浪启动

**关键区分: 洗盘 vs 出货**
- 洗盘: 低位涨停(<30%涨幅) → 倍量阴线 → 整理后站上P0 → 主力吸筹完毕
- 出货: 高位涨停(>30%涨幅) → 倍量阴线 → 持续下跌 → 主力出逃

### 信号检测规则

```
Day 0: 涨停, 收盘价=P0
Day 1: 高开(开盘>P0) + 低走(收盘<P0) + 倍量(量≥Day0×2)
Day 2-6: 整理期(5个交易日)
条件: 某日收盘价 > P0 → 站上涨停价
确认: 站上后连续2日收盘价 ≥ P0 → 信号触发
```

### 放弃条件

| 条件 | 说明 |
|------|------|
| 整理期收盘 < P0×0.90 | 跌幅超10% |
| 站上后收盘 < P0 | 突破失败 |
| 5天内未站上P0 | 整理超时 |

### 6个优化(2026-07-27)

1. **涨停前涨幅过滤**: 20日涨幅<30%才通过(低位涨停=洗盘,高位涨停=出货)
2. **底部保护收紧**: P0×0.85→P0×0.90(跌幅上限从15%收紧至10%)
3. **量能萎缩确认**: 整理期末量<倍量阴线×50%(浮筹清理完毕)
4. **MACD金叉加分**: +0.5分(额外加分,不计入基础6分)
5. **候选池自动补充**: 每日15:35复盘后自动补充核心个股
6. **创业板阈值**: 30xxxx/68xxxx用19.5%, 其他用9.8%
