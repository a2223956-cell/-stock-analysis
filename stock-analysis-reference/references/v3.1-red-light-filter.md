# V3.1 红灯板块过滤规则 (2026-08-04)

## 用户反馈

用户明确表示: "红灯期间完全不操作我觉得不太合适"

## V3.0 → V3.1 变更

```
V3.0: 红灯期间完全禁止买入
V3.1: 红灯期间只要板块强+个股满足三要素就可操作
```

## 板块过滤规则

```
板块相对强度 = 板块涨幅 - 上证涨幅

判断:
  > +0.5%  → 板块独立强 → 正常仓位(100%)    ✅可操作
  -0.5%~+0.5% → 板块中性偏强 → 仓位减半(50%)  ⚠️可小仓
  < -0.5%  → 板块偏弱 → 禁止操作(0%)        ❌禁止
  < -1.0%  → 板块拖累 → 禁止操作(0%)        ❌禁止
```

## 前提条件(必须同时满足)

1. 评分≥3.5(建仓候选)
2. 缩量比<0.8
3. K线信号(十字星/长下影/组合)
4. R:R>1.5

## 仓位管理

| 大盘信号 | 板块相对强度 | 最大仓位 | 评分门槛 |
|----------|-------------|----------|----------|
| 🟢 绿灯 | - | 20% | ≥3.5分 |
| 🟡 黄灯 | - | 15% | ≥4.5分 |
| 🔴 红灯+板块强 | > +0.5% | 20%(正常) | ≥3.5分 |
| 🔴 红灯+板块中性 | -0.5%~+0.5% | 10%(减半) | ≥3.5分 |
| 🔴 红灯+板块偏弱 | < -0.5% | 0%(禁止) | - |
