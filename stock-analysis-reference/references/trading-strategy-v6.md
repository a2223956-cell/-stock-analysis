## 二、策略二: 涨停洗盘后主升浪

### 核心逻辑(⚠️ 洗盘 ≠ 出货)

**洗盘**: 低位涨停(<30%涨幅) → 倍量阴线 → 整理后站上P0 → 主力吸筹完毕 → 主升浪
**出货**: 高位涨停(>30%涨幅) → 倍量阴线 → 持续下跌 → 主力出逃

⚠️ 同样的K线形态(涨停+倍量阴线),本质完全不同:
- 低位(<30%) + 整理后站上P0 = 洗盘(看涨)
- 高位(>30%) + 持续下跌 = 出货(看跌)

### 信号检测规则

```
Day 0: 涨停, 收盘价=P0
Day 1: 高开(开盘>P0) + 低走(收盘<P0) + 倍量(量≥Day0×2)
Day 2-6: 整理期(5个交易日)
条件: 某日收盘价 > P0 → 站上涨停价
确认: 站上后连续2日收盘价 ≥ P0 → 信号触发
```

### 放弃条件

| 条件 | 说明 |
|------|------|
| 整理期收盘 < P0×0.90 | 跌幅超10% |
| 站上后收盘 < P0 | 突破失败 |
| 5天内未站上P0 | 整理超时 |

## 八、关键教训(Pitfalls)

### 涨停洗盘 ≠ 涨停出货

⚠️ 2026-07-27教训: 我最初将策略二理解为"出货后搏反弹",用户纠正为"洗盘后主升浪"。

核心区别:
- 出货: 主力在高位卖出,股价后续下跌(短线投机)
- 洗盘: 主力在低位清洗浮筹,为后续拉升做准备(中线跟庄)

同样的K线形态(涨停+倍量阴线),判断依据:
- 涨停前20日涨幅: <30%=洗盘, >30%=出货
- 整理后能否站上P0: 能=洗盘确认, 不能=出货确认

⚠️ 2026-07-27发现: 每日大盘复盘任务(15:35)的"核心个股方向"输出,可以直接用于补充候选池,无需人工干预。

实现: 在复盘任务prompt中新增"角色6: 候选池自动补充",每日最多补充5只。
