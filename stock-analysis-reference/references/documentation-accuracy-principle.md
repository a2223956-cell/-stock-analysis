# 文档准确性原则 (2026-07-30)

## 问题

当skill文档中列出"已知局限"时,如果该局限已被后续版本解决,应更新文档状态,而不是继续列为"待解决"并提供"解决方案"。

## 用户纠正

"既然都有解决方案，为什么还说有局限性？"

## 正确做法

1. 检查每个"已知局限"是否已被后续版本解决
2. 已解决的: 更新为"✅已解决",注明解决方案和实施时间
3. 未解决的: 保持"⚠️待优化",提供解决方案
4. 使用表格格式清晰展示状态

## 示例

```
| 局限性 | 状态 | 解决方案 | 实施时间 |
|--------|------|----------|----------|
| 无基本面过滤 | ✅ 已解决 | V3.1确定性评估 | 2026-06-26 |
| 无大盘环境过滤 | ✅ 已解决 | 大盘环境过滤器 | 2026-07-30 |
| 震荡股效果差 | ⚠️ 待优化 | 需要ADX/布林带 | 计划中 |
```

## 适用范围

此原则适用于所有包含"已知局限"或"待优化"章节的skill文档。
