## 待从daily_stock借鉴的3个策略

### 1. 龙头策略(dragon_head)
```
触发: 板块启动或行业催化剂出现时
条件: 板块领涨地位 + 换手率>5% + 量比>1.5 + 相对强度
评分: sentiment_score +15
```
对stock-analysis的价值: 在板块分析时自动识别龙头,给龙头标的额外加分。

### 2. 箱体策略(box_oscillation)
```
触发: 价格在支撑/阻力间反复震荡
条件: 60日内3次以上触碰同一区域
操作: 箱底买入,箱顶减仓
```
对stock-analysis的价值: R:R计算可借鉴箱体思路,价格在箱体下轨时R:R更有利。

### 3. 预期差分析(expectation_repricing)
```
触发: 市场对公司业绩/政策/估值的预期正在变化
分析: 预期来源→预期差方向→兑现概率
```
对stock-analysis的价值: 估值分析(步骤6)可加入预期差维度。

## 结论

本地V2.2是最完善的版本,三个待借鉴策略可在后续版本中逐步纳入。
