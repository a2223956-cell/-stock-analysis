## 一、统一选股框架

```
全A股 → 统一过滤器 → unified_pool.txt(统一选股池)
                           ↓
                    每日扫描检测两种信号:
                    信号A: 缩量回踩 / 信号B: 涨停洗盘
                           ↓
                    actionable_pool.txt → 统一6维度评分 → 建仓
```

## 二、统一选股池过滤条件

| 条件 | 参数 | 说明 |
|------|------|------|
| 市值 | 80-300亿 | 中盘股,弹性好 |
| 成交额 | >1.5亿/日 | 真实流动性 |
| PE | 5-80 | 盈利+允许高成长(用户要求) |
| 股价 | >8元 | 排除低价股 |
| 上市天数 | >180天 | 排除次新 |
| ST | 排除 | 风险控制 |

预期池子大小: 300-600只

## 三、双信号检测

信号A [A] 缩量回踩: 缩量比<0.8 + K线形态 + R:R>1.5
信号B [B] 涨停洗盘: 涨停+倍量阴线+整理后站上P0(涨停前涨幅<30%)

## 四、执行节奏

周五16:00 → generate_unified_pool.py → unified_pool.txt
每日15:35 → scan_candidate.py → actionable_pool.txt
每日10:00/14:30 → 持仓检查 + 扫描actionable_pool
每周五15:30 → 周度复盘

## 五、Pitfalls

### 选股池过滤条件必须严格
初版条件(市值30-800亿/PE<80/成交额>5000万)导致2093只(39.6%通过率)=没过滤。
收紧后(80-300亿/PE 5-80/>1.5亿)→506只(9.6%),合理。

### PE上限80是用户明确偏好
用户要求从40提高到80,覆盖高成长股(机器人/AI/创新药等)。

### unified_pool ≠ actionable_pool
unified_pool.txt = 可交易范围(约500只)
actionable_pool.txt = 信号触发的股票(通常<20只)
