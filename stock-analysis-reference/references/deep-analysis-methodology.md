# 深度分析方法论（量价驱动型）

> 适用场景：用户要求对个股进行"深度分析"、"完整报告"、"主力行为判断"等

## 分析顺序（固定）

1. **市场环境扫描**（背景板） → 大盘指数 + 北向资金 + 板块涨幅 + 个股vs板块强弱
2. **量价关系**（核心） → 逐日K线 + 成交量，判断主力阶段
3. **资金流向验证**（数字印证量价判断） → 20日主力净流入/流出
4. **均线+技术面**（趋势配合） → MA5/10/20/30 + 偏离% + 多空排列
5. **估值+基本面**（安全边际） → PE/前向PE/PEG + 一致预期
6. **消息面+风险筛查** → 新闻情绪 + 公告 + 风险信号

## 量价分析核心框架

### 主力行为阶段判断

| 阶段 | 量价特征 | 资金流向验证 |
|------|----------|-------------|
| **建仓** | 股价低位横盘，成交量温和放大，涨时放量跌时缩量 | 主力净流入，散户净流出 |
| **洗盘** | 股价小幅回调，成交量明显萎缩（较前日缩30%+），下影线长 | 主力小幅流出或持平 |
| **拉升** | 连续阳线+成交量急剧放大（较前日放大50%+），换手率突破10% | 主力大幅净流入 |
| **出货** | 天量长上影阴线（成交量创新高但收盘低于开盘），或脉冲式拉高后连续大额流出 | 主力天量净流出 |
| **做T** | 日内大幅波动（振幅>8%），成交量中等，低开高走或高开低走 | 主力小幅净流出 |

### 关键K线分析模板

每根关键K线必须包含：
```
日期: YYYY-MM-DD
开盘/收盘/最高/最低价
成交量 + 与前日对比(放大/缩小百分之几)
换手率
这根K线说明主力在做什么，为什么这样判断
```

### 脉冲式出货模式识别

```
特征: 拉1天→出3天→再拉1天→再出3天
资金流向: +9亿 → -13亿/-8亿/-12亿 → +9.66亿 → -28亿/-17亿
判断: 典型"拉高出货"手法，用一天资金推升股价，随后高位大量派发
```

### 天量天价见顶模式（2026-07 实战验证）

```
特征: 股价创新高 + 成交量创历史新高 + 换手率>15%
实例: 凯盛科技600552
  6/29: 天量2449万手(较前日+59.7%)，收盘31.48，上影35%
  6/30: 高量2020万手，收盘32.58(新高)，上影33%
  7/1:  放量1942万手，暴跌-9.0%，跌破30元
  7/2:  继续暴跌-9.8%
  → 天量天价后连续暴跌，验证"天量见顶"规律

判断逻辑:
1. 天量=大量筹码换手，主力趁高位出货
2. 上影线长=上方抛压重，主力不愿继续拉升
3. 次日放量阴跌=确认出货开始
4. 缩量下跌=主力已出大部分货，散户恐慌抛售
```

## 评分体系

| 维度 | 权重 | 评分标准 |
|------|------|----------|
| 量价关系 | 30% | 建仓/洗盘=4-5分，拉升=3-4分，出货=1-2分，做T=2-3分 |
| 技术面 | 25% | 多头排列=4-5分，走平=3分，空头排列=1-2分 |
| 资金面 | 20% | 持续净流入=5分，小幅流出=3分，天量流出=1分 |
| 消息面 | 15% | 利多>利空=4-5分，中性=3分，利空>利多=1-2分 |
| 估值 | 10% | PEG<1=5分，PEG 1-1.5=3分，PEG>1.5=1-2分；**亏损企业用PB/PS替代** |

## 亏损企业估值框架（PE为负时）

当PE_TTM为负值时，**不能用PE/PEG估值**，改用以下框架：

| 指标 | 计算 | 参考区间 |
|------|------|---------|
| **PS（市销率）** | 总市值 / 年营收 | 半导体设计: 5-15x |
| **PB（市净率）** | 总市值 / 净资产 | 半导体: 3-6x |
| **营收增速** | (当期营收-上期)/上期 | >20% 为高增长 |
| **毛利率趋势** | 季度环比 | 产线爬坡期会承压 |
| **扭亏预期** | 机构研报共识 | 关注扭亏时间节点 |

**分析要点：**
- PS反映的是"营收能不能撑住市值"，亏损企业营收增速是核心
- PB反映的是"净资产够不够厚"，低于3x有安全边际
- 毛利率趋势是IDM/制造型企业的先行指标（良率→毛利率→扭亏）
- 机构预期扭亏时间决定了估值锚——距离扭亏越近，PS估值越合理
- 估值评分调整：PS<行业均值=3-4分，PS>行业均值=1-2分；PB<3=4分，PB>5=1-2分

## 阴跌阶段量价特征（补充）

| 模式 | 量价特征 | 资金流向验证 |
|------|----------|-------------|
| **缩量阴跌** | 连续小阴线，成交量逐日萎缩（较峰值缩50%+），换手率<3% | 主力小幅净流出或持平，散户承接 |
| **无量新低** | 创新低但成交量极低（较前日缩50%+），跌幅有限 | 卖压枯竭但买盘不足 |
| **反弹受阻** | 冲高回落长上影（上影线>实体），成交量较前日放大 | 主力借反弹出货，超大单净流出 |

## 关键K线模式速查

| 模式 | K线形态 | 含义 |
|------|---------|------|
| **断头铡刀** | 大阴线(实体>5%)，收盘近最低点，成交量放大 | 主力出货铁证 |
| **长上影出货** | 上影线>2元且>实体，成交量放大 | 上方抛压极重，借反弹出货 |
| **缩量新低** | 创新低+成交量较前日缩50%+，跌幅<5% | 卖压枯竭，等买盘信号 |
| **天量天价** | 股价创新高+成交量创新高+换手>15% | 主力对倒拉升或大额派发 |
| **脉冲式出货** | 拉1天→出3天→再拉1天→再出3天 | 用一天推升股价，随后高位派发 |
| **跳空低开探底回升** | 跳空低开+下影线长+振幅>5% | 有资金试探性抄底，但趋势仍向下 |

## 同花顺一致预期页面解析（basic.10jqka.com.cn）

### 关键表格索引

`pd.read_html()` 解析 `worth.html` 返回29+个表格，关键索引：

| 表格 | 内容 | 用途 |
|------|------|------|
| dfs[0] | EPS预测（年度/机构数/最小值/均值/最大值/行业平均） | 一致预期EPS |
| dfs[1] | 净利润预测（同上结构） | 一致预期净利润 |
| dfs[2] | 机构明细（机构名/研究员/各年EPS预测/净利润/报告日期） | 研报覆盖情况 |
| dfs[3] | 综合预测指标（营收/营收增速/利润/净利润/增速/EPS/现金流/ROE/PE） | 最全面的预测数据 |

### dfs[3] 关键行

```
行0: 营业收入(元) + 增长率
行1: 营业收入增长率
行2: 利润总额
行3: 净利润 + 增长率
行4: 净利润增长率
行5: 每股现金流
行6: 每股净资产
行7: 净资产收益率(ROE)
行8: 市盈率(动态) → 这就是前向PE
```

## 历史复盘模板（连续分析时使用）

当对同一股票进行多次分析时，报告开头必须包含历史复盘：

```
== 历史复盘: [股票名](代码) ==
  上次分析: YYYY-MM-DD | 当时价格: XX.XX元
  当前价格: XX.XX元 | 区间涨跌: ±X.X%
  上次结论验证: ✅/❌ × N条
  上次遗漏: [因素]
  本次需重点关注: [关注点]
```

**验证要点：**
- 量价判断是否被后续走势验证
- 操作建议是否有效（止损/止盈是否触发）
- 遗漏了哪些重要因素（大盘、板块、消息面）

## 北向资金数据源

- **hexin.cn**: 只有当日分钟级实时数据（262个时间点），无日级历史
- **东财datacenter**: `RPT_MUTUAL_DEAL_HISTORY` + `MUTUAL_TYPE="003"`，但部分IP返回空
- **东财kamt**: `push2his.eastmoney.com/api/qt/kamt.kline/get`，WSL下可能不可用
- **本地缓存**: 每次拉取实时数据后写入本地CSV，历史越跑越丰富

## WSL环境下东财API连接问题

WSL环境下 push2his.eastmoney.com **可能完全不可用**（2026-07-07 实测：urllib.request、curl、http.client 均持续 RemoteDisconnected）。push2.eastmoney.com 部分端点可用（slist板块归属、kline分钟资金流、kamt北向），但 push2his（日线K线、日线资金流）在部分IP上被永久风控。

### 降级策略

| 数据 | 主源(东财) | 降级方案 |
|------|-----------|---------|
| **K线数据** | push2his `/api/qt/stock/kline/get` | **新浪**: `https://money.finance.sina.com.cn/quotes_service/api/json_v2.php/CN_MarketData.getKLineData?symbol=sh600552&scale=240&ma=no&datalen=30` (UTF-8, JSON数组, 每条含day/open/high/low/close/volume) |
| **日线资金流** | push2his `/api/qt/stock/fflow/daykline/get` | push2 `/api/qt/stock/fflow/kline/get?klt=101` (仅返回当日，无历史) |
| **分钟资金流** | push2 `/api/qt/stock/fflow/kline/get?klt=1` | ✅ 通常可用 |
| **板块归属** | push2 `/api/qt/slist/get` | ✅ 通常可用（diff返回dict不是list） |
| **北向资金** | push2his `/api/qt/kamt.kline/get` | ✅ 通常可用 |

### 新浪K线API（可靠备用）

```python
import json, urllib.request, ssl

ctx = ssl.create_default_context()
ctx.check_hostname = False
ctx.verify_mode = ssl.CERT_NONE

url = "https://money.finance.sina.com.cn/quotes_service/api/json_v2.php/CN_MarketData.getKLineData"
params = "?symbol=sh600552&scale=240&ma=no&datalen=30"  # scale=240=日线
req = urllib.request.Request(url + params)
req.add_header('User-Agent', 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36')
req.add_header('Referer', 'https://finance.sina.com.cn/')
resp = urllib.request.urlopen(req, timeout=15, context=ctx)
data = json.loads(resp.read().decode())
# 返回: [{"day":"2026-07-06","open":"25.11","high":"26.08","low":"23.36","close":"23.55","volume":"106939368"}, ...]
# volume 单位是股（不是手）
```

- **优点**: WSL下稳定可用，不封IP，返回JSON数组直接可解析
- **缺点**: 不带MA数据（需本地计算），最多返回约1000根K线
- **注意**: 编码UTF-8（非GBK），stock代码前缀sh/sz
