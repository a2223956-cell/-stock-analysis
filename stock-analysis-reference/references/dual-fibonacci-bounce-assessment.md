# 双Fibonacci反弹评估框架 (2026-07-29新增)

> 来源: 许继电气+雷赛智能深度分析实战验证

## 核心问题

当个股经历大跌(-30%+)后出现V型反弹，如何判断反弹是"趋势反转"还是"弱势反弹"?

## 双Fibonacci框架

对于大跌后的反弹，必须同时用两个Fibonacci回撤来评估:

### A. 大级别回撤(从大跌起点到低点)

衡量反弹相对于整个下跌幅度的强度:

```
swing_high = 大跌起点(如涨停天量高点)
swing_low = 大跌终点(近期最低点)
range = swing_high - swing_low

fib_382 = swing_low + range × 0.382  # 38.2%回撤
fib_500 = swing_low + range × 0.500  # 50%回撤
fib_618 = swing_low + range × 0.618  # 61.8%回撤
```

**判断规则:**

| 反弹高度 | 含义 | 操作 |
|---------|------|------|
| 未到38.2% | 极弱反弹,大概率继续下跌 | 不参与 |
| 到38.2%受阻 | 弱势反弹,中期趋势未反转 | 观望,不追高 |
| 突破38.2%到50% | 中等反弹,有反转潜力 | 关注,等待确认 |
| 突破61.8% | 强势反弹,趋势可能反转 | 可考虑建仓 |

**关键教训(许继电气7/28案例):**
- 大级别38.2%回撤=21.78, 7/28收盘精确落在此位
- 38.2%支撑=反弹强度的"及格线",守住了才有后续

**关键教训(雷赛智能7/23案例):**
- 大级别38.2%回撤=60.76
- 反弹最高60.06/61.58均未有效突破60.76
- → 反弹在"及格线"附近受阻=弱势反弹,大概率不是趋势反转

### B. 小级别回撤(从低点到反弹高点)

衡量反弹后的回调支撑位:

```
swing_low2 = 反弹起点(近期最低)
swing_high2 = 反弹高点
range2 = swing_high2 - swing_low2

fib2_382 = swing_high2 - range2 × 0.382  # 38.2%回调
fib2_500 = swing_high2 - range2 × 0.500  # 50%回调
fib2_618 = swing_high2 - range2 × 0.618  # 61.8%回调
```

**判断规则:**

| 回调深度 | 含义 | 操作 |
|---------|------|------|
| 在38.2%上方 | 正常回调,反弹趋势完好 | 持有/小仓试探 |
| 在38.2%-50%之间 | 中度回调,需观察 | 观望 |
| 在50%-61.8%之间 | 深度回调,反弹可能失败 | 警惕 |
| 跌破61.8% | 反弹趋势结束,可能创新低 | 止损/清仓 |

## 实战案例

### 许继电气(000400) - 双Fibonacci精确支撑

```
大级别(从23.27跌至19.37): 38.2%回撤=21.78
小级别(从19.37反弹至23.28): 38.2%回撤=21.78

→ 大小级别38.2%回撤重合在21.78!
→ 7/28收盘21.78精确落在重合支撑位
→ 7/29逆势+1.42%确认支撑有效
```

### 雷赛智能(002979) - 反弹受阻于大级别38.2%

```
大级别(从76.26跌至51.18): 38.2%回撤=60.76
小级别(从51.18反弹至61.58): 38.2%回撤=57.61

→ 反弹最高60.06/61.58未能有效突破60.76(大级别38.2%)
→ 反弹在"及格线"附近受阻=弱势反弹
→ 回调至57.15,在小级别38.2%回撤(57.61)附近
→ 如果跌破小级别50%回撤(56.38),将测试61.8%(55.15)
→ 如果跌破55.15,反弹趋势可能结束
```

## 双Fibonacci的协同判断

当大级别和小级别的Fibonacci回撤位重合或接近时,支撑/阻力更有效:

| 情况 | 信号强度 | 操作 |
|------|---------|------|
| 大+小级别38.2%重合 | ⭐⭐⭐极强支撑/阻力 | 关键决策位 |
| 大级别38.2%与小级别50%重合 | ⭐⭐强支撑 | 重要观察位 |
| 无重合,各级别独立 | ⭐一般支撑 | 辅助参考 |

## 涨停出货后的反弹评估特别规则

涨停出货(7/1-7/6天量出货→暴跌)后的反弹,需额外检查:

1. **出货完成度**: 流出金额/流入金额 > 100% = 出货超额完成
2. **反弹高度**: 仅到大级别38.2% = 弱势反弹(大概率不是趋势反转)
3. **反弹量能**: 反弹日成交量 < 出货日成交量的50% = 量能不足以扭转趋势
4. **套牢盘压力**: 出货区间(60-76)的套牢盘会在反弹至该区间时形成巨大抛压

→ 四项中任意2项为负面 = 不应追反弹
