## 出货完成度计算

```
涨停期流入: +2.82亿
出货期流出: -4.73亿
净额 = -4.73 - 2.82 = -1.91亿 (主力净赚离场)

出货完成度 = 流出 / 流入 = 4.73 / 2.82 = 168% ← 超额完成!
```

**判断规则:**
- 出货完成度 < 100%: 出货进行中, 还有筹码要出 → 继续下跌
- 出货完成度 = 100%: 出货基本完成 → 可能企稳
- 出货完成度 > 100%: 超额完成(散户/融资盘/止损盘额外抛压) → 即使出货完成也可能继续阴跌

→ 结论: V型反弹≠趋势反转, 大概率只是超跌技术性反弹

## 与涨停洗盘的关键区别

| 维度 | 雷赛智能(涨停出货) | 福蓉科技(涨停洗盘) |
|------|-------------------|-------------------|
| 涨停前涨幅 | +29.8%(高位) | -10%(低位) |
| 涨停日量 | 放量(217K)+一字板 | 缩量(227K<均量) |
| 涨停后天量日 | 594K(7/6,高点当天) | 492K(7/17,洗盘日) |
| 出货完成度 | 168%(超额) | 不适用(非出货) |
| 暴跌幅度 | -32.6% | -10%(正常回调) |
| 后续走势 | V型反弹但弱势 | 持续反弹创新高 |

**核心区别: 涨停日的量能和位置**
- 放量涨停(>均量) + 高位(涨幅>30%) = 出货
- 缩量涨停(<均量) + 低位(涨幅<15%) = 洗盘
