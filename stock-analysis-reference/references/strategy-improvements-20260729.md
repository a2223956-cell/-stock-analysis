## 一、涨停洗盘形态严格条件(福蓉科技案例)

### 问题
福蓉科技7/28报告68.5分(🟢买入),基于"缩量涨停+天量洗盘"。7/29暴跌-3.90%,大盘+2.16%但个股逆势暴跌。

### 根因
5项检查仅2/5满足: ①7/17量比1.2倍(标准≥2倍)❌ ②P0反复跌破❌

### 硬规则: 5项必须全部满足才触发买入
```
[1] 涨停日收盘=P0 ✅
[2] 洗盘日量≥涨停日×2(倍量) ❌<2倍则信号无效
[3] 某日收盘>P0 ✅
[4] 站上后连续2日≥P0 ❌跌破则形态失败
[5] 涨停前20日涨幅<30% ✅
```
倍量是硬性条件,1.2倍≠2倍;P0必须站稳不能反复破。

## 二、R:R追高决策框架(泛微网络"还能追吗")

### 问题
用户问"30.4没买,现在30.80还能追吗?"

### 硬规则
```
追高R:R = (阻力-当前价)/(当前价-支撑)
等回调R:R = (阻力-回调价)/(回调价-支撑)
如果 追高R:R < 等回调R:R × 0.5 → 不追,等回调
如果 上方密集阻力<3% → 不追
如果 当日已涨>3% → 不追
```
泛微实例: 追高R:R=1.32 vs 等回调R:R=2.56 → 不追。好股票≠好价格。

## 三、大盘反弹+个股暴跌=个股层面问题(福蓉科技案例)

### 分析框架
```
大盘涨+板块涨+个股跌 → 个股层面问题(出货/利空)
大盘涨+板块跌+个股跌 → 板块层面问题
大盘跌+板块跌+个股跌 → 系统性风险
大盘跌+板块跌+个股涨 → 独立强势
```
福蓉: 创业板+2.16%但个股-3.90%+同板块其他标的暴涨=最高级别弱势信号,评分立即下调。

## 四、盘中多次追踪标准流程(许继电气4次追踪)

### 模式
同一交易日内多次分析同一只股票。

### 标准流程
```
第1次(开盘30分钟): 完整分析(建立基准)
第2次(间隔30分钟): 快速更新(价格变化+关键突破)
第3次(间隔30分钟): 趋势确认(突破/受阻+评分调整)
第4次(午盘前): 午后展望(关键价位+收盘预判)
```
第1次必须完整,后续只说变化部分。每次包含: 价格变化+关键突破+评分调整+操作建议。价格未显著变化(波动<1%)可简写"维持判断"。
